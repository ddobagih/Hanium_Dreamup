# WalkSafe 한눈에 보기

**개발 중 · 정식 검증 전 · 일반 배포 및 출시 미승인**

프로젝트 소개자료 · 공개 요약 PDF v1.1 · 기준일 2026-07-31

이 자료는 이해를 돕는 소개자료이며 제품 승인서나 안전성 증명서가 아닙니다.

## 한 문장으로

WalkSafe는 시각장애인의 도심 보행 중 가까운 위험과 큰 이동 방향을 알려
주고, 손상된 점자블록의 신고 준비를 돕기 위해 개발 중인 Android 보행 보조
서비스입니다.

## 어떤 문제를 해결하려 하나요?

도심을 걸을 때 화면을 계속 확인하기 어려운 사용자가 주변 위험과 이동
방향을 더 쉽게 알아차리도록 돕는 것이 목표입니다. 손상된 점자블록을
발견했을 때는 신고할 내용을 준비하고, 담당자가 검토한 뒤 기관에 전달할 수
있도록 돕는 흐름도 목표로 합니다.

WalkSafe는 탐지 결과나 경로가 언제나 정확하다고 전제하지 않습니다.
불확실한 정보를 안전한 것처럼 말하지 않고, 필요한 경우 안내를 제한하거나
멈추는 방향으로 설계하고 있습니다.

## 사용자는 무엇을 경험하게 되나요?

### 가까운 위험 알림

휴대전화 카메라와 기기 안에서 작동하는 인식 기능으로 가까운 보행 위험을
찾아 짧은 음성과 진동으로 알리는 것을 목표로 합니다. 위험을 놓치거나
잘못 알릴 수 있으므로 보조 정보로만 사용해야 합니다.

### 큰 이동 방향 안내

TMAP이 제공하는 보행 경로 정보를 이용해 목적지까지의 큰 이동 방향을
안내하는 것을 목표로 합니다. 안전한 길을 보장하거나 모든 장애물과 도로
상황을 판단하는 기능은 아닙니다.

### 손상된 점자블록 신고 준비

사용자가 손상된 점자블록의 신고 내용을 준비할 수 있게 하는 것이
목표입니다. 신고 후보는 지정된 담당자의 검토와 기관 전달 준비를 거치며,
기관에 자동 접수되는 기능을 뜻하지 않습니다.

## 제품은 어떻게 구성되나요?

### Android 사용자 앱

가까운 위험 알림, 큰 이동 방향 안내, 점자블록 신고 준비를 담당합니다.
현재 구현과 내부 확인을 진행하고 있습니다.

### 별도 Android 관리자 앱

신고 내용을 검토하고 기관 전달을 준비하며 처리 기록을 관리합니다. 사용자
앱과 분리해 구현하고 있습니다.

### 중계·서비스 서버

로그인, 경로 검색, 신고 처리처럼 앱에 필요한 서버 기능을 제공합니다.
가까운 위험 인식은 휴대전화 안에서 처리하는 방향이지만, 로그인·경로·신고
정보에는 서버 기능이 필요합니다. 실제 수집·보관·삭제 방식은 정식 공개
전에 검증하고 사용자에게 명확히 알려야 합니다.

과거에 만든 웹 화면은 개발 참고자료로만 보존하며 현재 제품이나 출시
대상이 아닙니다.

## 현재 상태와 앞으로 할 일

### 지금 어디까지 왔나요?

WalkSafe는 외부 배포 전 개발 단계입니다.

- 기능 구현과 개발 자료 점검을 진행하고 있습니다.
- 정식 제품 시험과 출시 전 점검은 아직 시작 전입니다.
- 출시 판단에 필요한 실제 휴대전화와 현장 검증 증거가 아직 없습니다.
- 일반 배포와 출시는 승인되지 않았습니다.

개발 자료 점검이 통과했다는 사실은 작업을 이어갈 수 있다는 뜻입니다.
제품의 안전성, 현장시험 또는 출시 승인을 뜻하지 않습니다.

### 앞으로 무엇이 남았나요?

1. 남은 기능과 안전·보안·개인정보·운영 요구사항을 구현하고 내부
   검증합니다.
2. 시험에 사용할 하나의 고정된 앱·서버 묶음을 만들고 관련 문서와 추적
   기록을 완성합니다.
3. 계획된 정식 시험을 같은 앱·서버 묶음으로 수행합니다.
4. 승인된 휴대전화와 참여자를 대상으로 접근성, 현장 보행, 장시간 사용,
   장애 복구와 용량을 검증합니다.
5. 출시 전 점검과 독립 검토를 실제 증거로 모두 마칩니다.
6. 별도 출시 승인을 받은 뒤에만 제한된 공개와 운영을 시작합니다.

### 꼭 알아야 할 안전 한계

- WalkSafe는 보행 안전을 보장하지 않습니다.
- 흰지팡이, 안내견, 보호자나 기존 보행 지원을 대신하지 않습니다.
- 카메라 가림, 휴대전화 장착 상태, 배터리, 발열, 센서, 네트워크와 주변
  환경에 따라 안내가 늦거나 틀리거나 나오지 않을 수 있습니다.
- 경로 안내는 큰 이동 방향을 돕는 정보이며 안전한 통행 가능 여부를
  보장하지 않습니다.
- 정식 안전 검증과 출시 승인이 끝나기 전에는 WalkSafe의 안내에 의존해
  실제 보행에 사용하면 안 됩니다.

## 자주 묻는 질문

### 지금 누구나 내려받아 사용할 수 있나요?

아닙니다. 현재 일반 배포와 출시가 승인되지 않았습니다.

### 앱이 알려 주는 대로 걸으면 안전한가요?

아닙니다. 알림과 길안내는 보조 정보이며 놓침과 오판 가능성이 있습니다.

### 웹 화면도 현재 제품인가요?

아닙니다. 현재 개발 대상은 Android 사용자 앱과 별도 Android 관리자
앱입니다. 과거 웹 코드는 개발 참고자료입니다.

### 점자블록 신고가 바로 기관에 접수되나요?

아닙니다. 지정된 담당자의 검토와 기관 전달 준비가 필요하며 자동 접수를
뜻하지 않습니다.

### 사진과 위치 정보가 모두 휴대전화에만 남나요?

그렇게 단정할 수 없습니다. 가까운 위험 인식은 휴대전화 안에서 처리하는
방향이지만 로그인, 경로 검색과 신고 처리에는 서버가 사용됩니다. 정식
공개 전 실제 데이터 흐름과 보관·삭제 방식을 검증하고 고지해야 합니다.
