adb install -r로 기존 앱 데이터와 권한을 보존했습니다. 현재 런타임 권한은 모두 허용 상태라 첫 권한 팝업은 다시 나오지 않을 수 있습니다. 일회성 최초 권한 요청부터 다시 시험하려면 앱 데이터 초기화가 필요하며, 기존 로그인·설정이 삭제되므로 별도 확인 후 진행해야 합니다.

원하는 동작 기준

  1. 최초 앱 진입 때 누락된 카메라·정확한 위치·마이크·신체활동·알림 권한을 한 번의 요청 흐름으로 시작합니다. Android가 권한 종류에 따라 시스템 창을 여러 개로 나눠 표시할 수 있습니다.
  2. 권한을 거부해도 앱 전체를 막지 않고, 거부한 권한과 직접 관련된 기능만 제한합니다.
  3. 회원가입은 이용약관·개인정보·위치 약관의 필수 3개 중 하나라도 동의하지 않으면 완료되지 않습니다. 원본 제공·자동 신고·학습 재사용 선택 3개는 거부해도 가입할 수 있습니다.
  4. 로그인과 안전 고지 뒤 기기점검 버튼을 한 번 누르면 휴대폰 사양·기능을 한 번 측정합니다.
  5. FULL이면 모든 지원 기능으로, LIMITED이면 미달 항목과 연결된 기능만 제한한 채 다음 단계로 넘어갑니다. 측정 자체가 실패한 FAIL만 재시도가 필요합니다.
  6. 완료된 FULL/LIMITED 결과는 같은 계정·기기에서 복원되어, 앱을 다시 열 때 불필요하게 재측정하지 않습니다.

  • 반영: 회원가입 동의/상세 2단계, 필수·선택 약관 카드, 뒤로가기 배치
  • 반영: 보행 화면 구역·구분선·2열 동작 버튼, 마지막 음성 결과
  • 반영: 목적지 입력 TalkBack 이름, 경로 이탈 시각 안내, 스크롤/전체 화면 채움, TTS 데이터 설치 복구
  • 남은 P2 시각 차이: 밝은 팔레트, Pretendard, 전역 버튼·입력칸·상태 카드 마감
  • 제외: 현재 안전고지·기기점검·결과 복원·보행 제어를 퇴행시키는 과거 구조와 기능 무관 기록/환경 변경

독립 재검수에서 누락된 사용자 체감 P0/P1은 발견되지 않았습니다. 남은 항목은 기능 결함이 아닌 전역 외형 선택이며, 밝은 테마만 단독 적용하면 현재 어두운 프로그램식 화면과 대비가 깨질 수 있어 묶음 디자인 결정으로 남겼습니다.

지금 확인할 순서

  1. 위 아이디·비밀번호로 로그인
  2. 안전 고지를 읽고 확인
  3. 기기점검 화면에서 버튼을 한 번만 누르기
  4. 한국어 TTS, 호출어/마이크, GPS, 진동, CameraX·탐지, 배터리·저장공간·발열, 거리 측정 결과 확인

  6. LIMITED라면 제한 사유가 고지되고 해당 기능만 비활성화되는지 확인
