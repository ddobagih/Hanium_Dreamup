## 적용한 동작

- 같은 계정·같은 휴대폰에서는 완료한 기기점검과 연습을 재사용한다. 미완료 연습은 저장된 진행을 이어가며, 재로그인이 최신 진행을 이전 단계로 되돌리지 않는다.
- 사용자가 확인한 대로 새 휴대폰에서는 기기점검과 연습을 모두 다시 진행한다. 설치 식별자가 다른 교육 기록은 복원하지 않고 원본도 삭제하지 않는다. 식별자가 없던 예전 부분 기록은 기존 휴대폰의 로컬 기록으로 호환한다.
- 최초 명시 기기점검은 내장 이미지로 CPU·GPU를 실행해 선택한다. 정상 홈·카메라 진입은 저장된 선택을 준비하며 비교를 반복하지 않는다. 기존 미측정 기록은 명시 점검에서 보완한다.
- 일반 모델 준비 후 명시 점검을 요청한 경우에도 이전 native 작업·해제를 확인한 뒤 비교한다. 취소·종료·해제 실패·보행 및 보정 중 교체를 방어하고 새 모델 인스턴스의 실행 검증을 유지한다.
