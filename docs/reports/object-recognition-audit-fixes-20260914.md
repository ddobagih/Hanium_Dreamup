# 독립 검수 후 객체 인식 개선 계획과 결과

## 목표와 범위

독립 검수에서 재현한 보행 경고 지연·취소, 추적 예산에 따른 후보 소실, 혼합 깊이의 근거리 누락, 마스크 병합·부분 보정 범위에서 관측 소실, Raw/Full 교대 시 움직임 이력 초기화, 세로 회전의 경계 좌표 탈락을 수정한다. 기존 WIP와 모델 가중치·768 입력·사용자 데이터·시험 모드의 안내 시작 우회를 보존한다.

현재 모델의 사람 인식 성능, FastSAM의 입력 회전별 정확도, 실제 보행 정답·지연은 코드 회귀와 별개다. 기존 정답 자료로 검증할 수 있는 범위를 기록하고 새 학습·현장 성능을 측정했다고 주장하지 않는다.

## 시작 시 재현 기준

- 내부 MessagePolicy/최종 큐 중복 제한: 최초 1m STOP 관측 후 2,500ms에 첫 action, 33ms 뒤 전달 키 소실.
- 추적: 네 번째 전방 물체는 OBJECT_BUDGET_EXCEEDED, 129·300개 입력은 observations=0.
- 혼합 깊이: confidence255인 3,364개 중 580개가1m, 나머지가8m인 연결 마스크가 KNOWN8m → 원거리 숨김.
- 병합: 두 반복 마스크가1m에서 합쳐지면 AMBIGUOUS, objects=0, show=false. 부분 보정 범위도 show=false.
- 움직임: Raw4개만 쓰면 약1m/s·TTC3,099ms, 중간 Full3개가 있으면 speed/TTC=null.
- 회전: 가장자리 정상 박스가 역회전 뒤 y=-2.9802322E-8이 되어 INVALID_GEOMETRY.

시작 기준은 독립 검수의 현재 코드 호출·합성 입력 재현이다. 야외 발생 빈도는 측정하지 않았다. 이전 설치 APK는 SHA256 `39fb158652c07dabad05e9a4f6c245fa975fb9fc948321a987fcbb4536c45659`이며, 이 문서의 새 구현·검증 결과와 구분한다.

## 구현 내용

### 1. 경고 후보와 발화 간격

ObjectDepthRuntimePipeline은 매 관측마다 현재 경고 후보를 보존하고, 최종 WalkSafeFeedbackPolicy 큐가 실제 반복·만료·전달 확인을 담당한다. 독립 MessagePolicy의 기본 제한은 유지한다. 보폭 갱신은 사용자 지정 설정·히스테리시스 상태를 보존한다. 동일 합성 입력에서 최초 action 후보가 2,500ms에서 안정화가 충족되는 800ms로 앞당겨졌고, 33ms 다음 프레임에도 전달 키가 남았다. 실제 스피커 발화 시각 측정은 아니다.

### 2. 추적 후보와 세로 경계

검출 300개 계약을 받아 원본 인덱스를 보존한다. 촬영 프레임 자체에는 유효 geometry 전체를 제공하고, 이후 프레임에는 기존 계산 예산 안에서 최대 3개를 전파한다. 이 3개는 같은 촬영 프레임의 실측 위험, 세로 방향을 반영한 전방 위치, 검출 배치 간 순환 순서로 선택한다. 나머지는 LOST로 명시해 오래된 박스를 현재 거리 근거로 재사용하지 않는다. 동시 모든 객체의 연속 추적을 구현한 것은 아니다.

회전은 끝점 기준으로 변환하고 ±1e-6의 부동소수점 경계 오차만 보정한다. 실제 화면 밖·NaN·잘못된 크기는 계속 거부하며 letterbox padding에만 걸친 면적 없는 검출을 일찍 제외한다. 기기 점검의 고정 자료 전처리는 실제 인식의 bilinear 방식으로 맞췄다. 사용하지 않는 live 점검 경로까지 세로 회전 처리를 통일했다고 주장하지 않는다.

### 3. 미학습 객체의 가까운 표면

혼합 깊이에 독립적으로 지지되는 근거리 연결 영역이 있으면 먼 배경을 전체 물체 거리로 확정하지 않는다. 실제 깊이 표본의 영역·거리만 별도로 보존하며, 전체 물체의 크기나 접근 속도로 확대하지 않는다. 마스크 병합으로 ObjectTracker ID가 불확실해져도 현재 근접 관측은 별도 영역 ID로 유지한다. 3회·700ms 안정화, 신선도·품질 검사를 통과한 근접 관측만 기존 공용 음성 큐로 전달한다. 부분 보정 범위의 관측은 거리 미확인으로 보여주되 전체 거리·크기·경고를 보류한다.

추가 근거리 영역은 연결된 robust 표본 12개 이상 및 내부 면적 10% 이상 조건을 각각 충족해야 한다. 흩어진 1m 잡음은 수가 많아도 이 조건으로 승격되지 않는다. 이 숫자를 실제 보행 누락·오탐의 최적값으로 검증한 것은 아니다. MaskDepthEstimator 정책 ID는 V3로 바꿨다. V2 결과가 동일해야 한다는 과거 속도 비교 시험은 새 정책의 의미 동등성 시험으로 재사용하지 않는다.

### 4. Raw/Full 움직임 이력

Full 관측에는 별도의 근접 거리·급변 이력을 사용한다. 사이에 Full이 들어와도 Raw의 독립 관측 이력은 보존하며, Full 프레임에서 이전 Raw 속도나 TTC를 새로 측정한 값처럼 출력하지 않는다. 긴 공백·기준 좌표계 변경·Raw 재사용·깊이 급변에서의 초기화는 유지한다. Main의 생성 6곳과 카메라·미학습 경로를 연결했다. 같은 Raw 입력의 단독/Full 혼합 재현은 모두 약 1m/s·TTC 3,099ms였다.
