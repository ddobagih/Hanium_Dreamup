1. 중단 시점 로그와 실제 취소 경계를 분리한다.

## 발견한 별도 코드 결함

테스트 시작은 `isStartupCapabilityConfirmed()`가 true이면 저장된 `confirmedStartupCapabilityDecision` 없이도 진행된다. Depth의 거리 제한 모드 전환은 이 공통 판정 대신 저장 객체 일치를 직접 요구했다. 따라서 같은 테스트 보행이 전환 시 미확인 상태로 취급되어 재확인·경로 삭제·TTS 종료로 이어질 수 있었다. 변경 전 확인 상태를 공통 판정으로 캡처하도록 통일했다. 이 코드 결함이 09:19 실기기 중단의 직접 원인이라는 사실까지 입증된 것은 아니다.
