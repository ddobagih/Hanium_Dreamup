# 객체 인식 v5 개선 계획과 검증

## 목표와 범위

독립 검수 3건(추적 복구 ID 초기화, Camera 경고 대표 전환, GPS 제한 시 전달 상태 누락)을 수정한다. 이어서 PRIMARY 학습 모델과 FastSAM이 같은 물체를 감지한 경우 카메라 화면에서 하나로 표시한다. 위험 범위 및 작은 미학습 물체의 표시·음성 기준은 현행 코드로 답한다.

기존 모델/768 입력, 사용자 데이터, 현재 안내 시작 우회 설정을 유지한다. 모델 두 개의 원본 결과는 각각의 거리·위험 근거로 보존하며, 동일 물체의 표시와 경고 대표를 통합한다. 별도 장애물을 단순히 상자가 겹친다는 이유로 제거하지 않는다. Raw가 시간 연속성에서 탈락할 때 Full을 재평가하는 제안은 아직 측정 정답이 없는 별도 개선 후보로 둔다.

## 사용자 질문: 위험 범위와 작은 객체

FastSAM은 학습 모델의 21개 클래스 밖인지만 판단하는 분류기가 아니다. 이름 없이 물체/표면의 영역을 나누므로 사람·차량도 다시 감지할 수 있다. 이번 통합은 두 모델의 원본 추론을 유지하면서 최종 화면의 동일 객체를 하나로 표시하는 변경이다. 실제 촬영 시점·위치·깊이·유일한 대응이 확보되지 않은 후보까지 무조건 지우지 않는다.

### 음성 안내 범위

현재 모든 사각형을 읽지는 않지만, 사용자의 실제 진행 경로와 몸 폭에 들어오는 객체만 읽는 구조도 아니다.

- 학습 객체: 화면 중앙 여부는 신뢰도 가중치다. 가까운 옆쪽 객체도 위험 조건을 충족하면 안내할 수 있다.
- 미학습 영역: 세로로 바로 선 화면 기준 가로 25~75%, 세로 12~95%의 띠에 마스크 픽셀이 20% 이상 들어와야 후보가 된다. 접근 중이 아닌 4m 초과 영역은 제외한다. 이 화면상의 조건이 실제 지면 보행 궤적과 같은 것은 아니다.
- 공통 위험 안내: 기본 3회/700ms 관측, 유효 거리/신뢰도, 촬영 시각과 공용 출력 큐를 확인한다. 거리 1.2m 이내 STOP, 2.5m 이내 WARNING 또는 높은 신뢰도에서 STOP. 접근 객체는 TTC 3초/10초 경계도 사용한다. 이 숫자들은 정책 설정이며 현장 안전성을 보증한 측정값이 아니다.
- Main의 비계량 카메라 대체 경로에는 별도의 좌/중/우 객체 관측 안내가 있다. 이 음성은 거리나 충돌을 확정하는 경고가 아니며, 독립 카메라 테스트 화면은 해당 경로를 사용하지 않는다.

### 작은 물체를 남기는 수준

| 단계 | 현재 기준 | 의미 |
|---|---|---|
| FastSAM 추론 | 입력768, 점수>0.25, 원시 마스크 최대100개 | 실제 최소 몇 cm 물체까지 인식하는지는 검증되지 않음 |
| 후보 표시 | 전방 영역·거리·관측 조건으로 선별 후 미학습 추가 표시 최대6개 | 화면 표시는 음성 안내보다 넓은 조건 |
| 작은 점 제외 | 2.5m 이상, 안정적·비접근, 3회/700ms, 화면 면적≤0.1%, 화면 폭/높이 각≤4%, 보수적 관측 폭/높이 각≤4cm | 모든 조건과 신뢰할 Raw Depth 조건을 만족할 때만 제외 |

따라서 **4cm 미만을 전부 무시하지 않는다.** 가까운 물체, 접근하는 물체, 길거나 가느다란 장애물, 거리/크기를 확인하지 못한 영역은 남을 수 있다. 작은 박스는 물체 전체가 아니라 분할된 표면 일부일 수도 있다. 화면의 작은 박스 수와 실제 불필요한 경고 수는 별도로 평가해야 한다.

작은 영역이 많은 이유에 대한 코드 근거는 확인했지만, 최소 검출 크기나 현장 검출률을 측정한 것은 아니다. 크기 문턱을 단순히 올리면 발밑 장애물도 빠질 수 있어 이번에는 작은 물체 선별 기준을 임의로 높이지 않는다. 정답 자료를 확보하면 작은 위험물의 누락과 무해한 작은 영역의 오경고를 함께 비교한다.
