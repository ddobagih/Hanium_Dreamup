## 연결부와 독립 리뷰에서 추가 보완한 사항

- U2는 알고리즘 이력 보존만으로 끝내지 않았다. 재사용 Depth의 빈 결과가 Main/Camera의 기존 발화 근거를 지우는 경계를 보완했다. 현재 마스크·같은 Depth로 확인한 `retainedProximityRegionIds`에 해당하는 기존 경고만 원래 frame/capture/deadline 그대로 보존한다. 새 관측 수나 유효시간은 늘리지 않는다. 실제 소실·다른 context·만료 시 새 발화는 차단한다.
- F2 완료는 시작 신선도와 분리하지만 UNKNOWN context identity·현재 세션·취소 경계는 유지한다. 명시적 context 무효화는 해당 prefix의 claim/queue와 타이머만 취소하여 PRIMARY와 다른 context를 보존한다. 일반 후보 소실은 이미 시작한 출력의 실제 완료를 취소하지 않는 기존 의미를 유지한다.
- T1 첫 수정은 원본 검출 좌표만 대응하여 이동 추적이 연속이어도 ID가 바뀌는 회귀가 있었다. 독립 리뷰의 192px 고정 텍스처·50ms마다 7px 이동 재현에서 기준본 ID 1개→첫 수정 2개→최종 1개를 확인했다. 유효한 현재 추적 대응도 모호성 검사에 포함하고 예산 대기·실제 실패 뒤의 오래된 좌표는 대응 자격에서 제외했다.
- T1 전체 검출은 원본 시각의 ID 확인에만 사용하고, 실제 현재 추적 좌표만 Depth·경고에 넘긴다. 미선택 객체의 오래된 상자를 현재 좌표로 출력하지 않는다. 예산 대기는 깊이 정보 시각을 보존하여 재사용 Depth가 독립 표본으로 다시 세어지지 않게 했다.
- M2는 Main 원본/현재 프레임, Camera, Unknown의 캡처 회전을 모두 연결했다. 정면·구역·비계량 접근만 upright로 판단하고 센서 polygon·Depth/3D 투영은 유지했다. 회전 미확인은 보수적으로 처리한다. 기존 높은 신뢰도 STOP과 대체 방향 문구도 보존했다.
