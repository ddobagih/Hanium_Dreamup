- 깊이 담당: DepthContracts, DepthEstimator, ObjectTracker, 단기 예측 helper 및 관련 회귀.
- 캡처 담당: MotionContext, ArCoreFrameProvider, 중력/평면 값 복사 및 회귀.
- 선별 담당: UnknownWalkingObstaclePolicy, 순수 공간 판정 helper 및 회귀.
- 평가 담당: 고정 자료·이전 버전 보존, 실제 생산 코드의 비교 adapter, 정답을 사전 명시한 합성 장면.

- 독립 검토: 구현 파일을 수정하지 않고 원실패·인접 경계를 확인한다.

## 설계에서 구분할 사항

객체 ID의 유지와 현재 거리를 알고 있다는 판단은 다르다. 예측 거리에는 원측정 시각·오차·만료를 붙이고 실측 거리와 분리한다. GNSS 진북 방향을 AR anchor 방향으로 그대로 섞지 않는다. 현재 앵커는 최초 카메라 자세로 생성되므로 anchor Y를 중력으로 가정하지 않고 같은 캡처의 world-up 변환을 추가한다.

FastSAM 내부 추론은 영상 전체에서 영역을 만들고, 결과를 깊이와 연결한 뒤 3m 밖을 제외한다. 이 제한 자체가 모델 계산량 감소를 의미하지 않는다. 3m는 카메라에서 신뢰할 가까운 표면까지의 실제 거리로 정의하며 축거리만으로 옆쪽 영역을 통과시키지 않는다. 예측으로 표시하려면 오차를 포함한 거리 상한도 3m 이내여야 한다. 새 거리/TTC 발화의 실측 자격은 예측으로 충족시키지 않는다.

바닥 평면 후보는 ARCore가 추적하는 유한한 수평 표면이며 바닥의 의미를 보증하지 않는다. 카메라 발밑 투영의 포함·낮은 위치·넓이·현재 깊이 일치를 확인해야 억제 근거로 쓴다. 단순 작은 박스 또는 평평한 모양만으로 물체를 삭제하지 않는다.

### 적용 기준과 예외

- 통로 기준은 추정 진행 방향의 좌우 약0.75m(기본 반폭0.60m+여유0.15m)다. 실제 경로 지도를 AR 좌표에 정합한 영역은 아니다. 신뢰할 pose 이동이 없으면 카메라 정면의 근사이며, 중력도 없으면 기존 화면 중앙 영역 선별을 보수적으로 사용한다.
- 바닥 후보는 카메라 아래1.1~2.2m, 발밑까지 포함하는 충분한 넓이의 현재 수평평면이어야 한다. 현재 장면 깊이의 연속성, 실제 마스크 깊이의 평면 잔차 등도 확인한다. ARCore 평면 자체를 바닥 의미 라벨로 취급하지 않는다.
- 크기 하나만으로 작은 물체를 없애지 않는다. 좁거나 낮거나 머리 높이의 실제 장애물도 유지한다. Raw의 강한 공간 근거가 부족하거나 Full만 있으면 바닥/측면을 쉽게 무해로 단정하지 않는다.
- 큰 배경 마스크 안의 가까운 연속면은 전체 면적의10%보다 작더라도 Raw30개/Full50개 이상의 연결된 실제 점, Raw신뢰도192/255 이상, 깊이 분산 기준을 만족하면 별도 지지 영역으로 보존한다. 새 근접 안내는 기존3회/700ms 안정 기준도 통과해야 한다. 분산 잡음·표본수/신뢰도 미달 경계는 거부한다.
- 3m는 후보의 최대 범위다. 모든3m 이내 영역을 말하는 것은 아니다. 기존 정지/주의 거리·접근 근거·신뢰도·우선순위 조건을 추가로 통과해야 한다.
- FastSAM 전체 영상 추론은 그대로이며, 깊이로 후속 결과를 선별한다. 이번 3m 제한이 신경망 연산량 감소를 뜻하지 않는다.

### 깊이 공백과 앱 연결

단순 Depth 누락 때도 현재 RGB 좌표 변환을 보존하여 원래 ID의 공백 상태 처리까지 전달한다. 사용한1×1 변환 그리드는 정규화 좌표용이며 실제 depth 배열이나 실측 표본을 만들지 않는다. 새로 측정된 부분 표면이 기존 대표와 달라지면 과거 예측으로 덮지 않는다.

예측은 실측 거리 이력·새 속도·TTC·음성 자격을 갱신하지 않는다. 기존 유효 경고의 ID를 유지할 때도 원래 캡처와800ms 만료를 보존한다. 예측 표시에서는 객체별 더 짧은 유효기간이 우선한다. FastSAM 처리 지연과 화면 큐 대기 시간을 차감하고, 카메라가 멈춰도 타이머가 만료된 수치/상자를 제거한다.

Main의 짧은 공백 처리는 같은 세션·현재 추적·기존 실제 Depth 후600ms 이내에서만 허용한다. 이 기간을 새 Depth로 갱신하지 않으며, 기존 metric 안내·신고 gate와 유효 시각 대입은 유지했다. 카메라 시험 화면도 동일한 만료 기준을 적용했다.
