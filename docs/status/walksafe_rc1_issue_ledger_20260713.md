## Product decisions recorded — 2026-07-16

1. Web: metric tactile local steering은 projection evidence가 없어 비활성으로 유지한다. 별도 `CAMERA_NON_METRIC_ADVISORY`는 폭넓은 Web에서 low 방향 보조 경고만 제공하고 TMAP이 경로 권한을 유지한다.
2. Android compatibility: ARCore 미지원 단말도 설치 가능하며 CameraX+TFLite+fresh IMU+활성 TMAP의 `CAMERA_IMU_NON_METRIC` 제한 모드를 사용한다. gate 실패 시 `TMAP_ONLY`, reports=false다.
3. Equal-severity risks: option 3A인 bounded sequential handoff를 사용하고 전달 직전에 tier·lifecycle·freshness를 다시 확인한다.
4. Source freeze: 최종 gate를 통과한 현재 전체 변경을 승인된 source-freeze snapshot으로 채택하고 local commit만 허용한다. push는 승인 범위에 포함되지 않으며 Field·Release 완료를 뜻하지 않는다.
