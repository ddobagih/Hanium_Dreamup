## 발견사항 — 최초 버전

### RV01 — 문서 오류: 1500ms 목표 span을 scalar 회귀 필수 하한으로 기재

- 대상: P-D07-008 criteria 및 회귀 span threshold, `diagrams/D07-F008.mmd` P1.
- `MotionObservationWindow.sample`은 4표본과 1500ms를 확보하면 탐색을 끝내지만, 미달 시에도 현재 선택된 표본을 반환한다. `ObjectTracker.approachKinematics`의 독립 모드 span은 `600..4000ms`, 간격은 `100..1500ms`이다. `linearDistanceTrend`는 1500ms 하한을 검사하지 않는다.
- 따라서 다른 안정도·통계 자격을 충족한 4표본/600ms를 본문이 과도하게 거부한다고 설명한다. **1500ms 수집 목표와 실제600ms 하한을 분리**하고 도표의 scalar/spatial 자격을 분리하도록 작성자에게 요청했다.
- 제품 변경 요청 또는 실제 오작동 재현이 아니다.

### RV02 — 문서 오류: unknown lease equality 만료 경계

- 대상: P-D07-019의 lease threshold boundary `현재시각 이하 만료`.
- `UnknownObjectFeedbackBatch.isFreshAt`는 `now <= validUntil`를 허용한다. **`now > deadline`이면 만료, equality 허용**으로 수정 요청했다.
- `UnknownObjectFeedbackPolicyTest.admittedFeedbackUsesTheFrozenElapsedCaptureRatherThanTheRawCameraClock`의 assertion은 원 capture+800ms 기한과 +801ms 거부 기대를 명시한다. 이번 시험은 실행하지 않았다.

### RV03 — 도표 오류: 실제 효과보다 admission 거부 분기가 뒤에 있음

- 대상: `D07-F008.mmd`, `D07-F009.mmd`, `D07-F019.mmd`, `D07-F030.mmd`, `D07-F032.mmd`.
- F009는 PREDICTED 반환, F019는 queue 전달, F030은 semantic 획득·close, F032는 warning mute 노드를 먼저 거친 다음 D에서 실패·disabled·만료를 분기한다. 실행 흐름으로 읽으면 거부 입력도 효과에 도달한다.
- 소스는 해당 조건에 early return하거나 유효 결과/그룹이 생긴 뒤에만 효과를 수행한다. **효과 노드 앞에 자격 분기를 배치**하도록 요청했다. F008은 scalar와 actual point 3D의 별도 경로를 먼저 나누고 nonclosing veto에서 합류하도록 요청했다.
- 본문은 대체로 올바른 거절 결과를 설명하므로 제품 동작 변경을 요구하지 않는다.

### RV04 — 추적성 오류: 정책 수치 출처 경로를 첫 파일로 일괄 지정

- P-D07-003의 clock64는 `DepthCaptureTimes.kt`, display/risk age는 `DepthAgeBudget.kt`, reprojected .70은 `DepthFrameSnapshot.kt`인데 threshold source가 모두 `CoordinateMapper.kt`로 되어 있다.
- P-D07-008의 3D motion·CPA 관련 상수 일부도 `TrackerRiskPolicy.kt` 등에 있으나 `MotionObservationWindow.kt`로 일괄 표기되었다.
- 각 수치의 실제 선언/적용 파일과 심볼로 바꾸도록 요청했다. feature의 code_refs가 여러 파일을 포함한다는 사실만으로 잘못된 세부 출처를 정확하다고 처리하지 않았다.
