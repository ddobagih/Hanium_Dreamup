제품 코드의 정적 경계와 실행 미확인

  • 추가 관찰: voice/inference_process.py:85–101은 executor 참조를 먼저 None으로 바꾸고 terminate/join1초/kill/join1초를 시도한다. 마지막 join 뒤 생존 재검사 또는 불확실 handle을 보존하는 코드가 없어, 이 설명을 자식 종료 확인의 절대 보장으로 확대하면 안 된다. 작성자가 F006 notes에 종료 시도의 범위와 마지막 생존 재검사 부재를 명시했고 재검토했다. 제품 수정은 요청하지 않았다.
  • D13 연계: require_current_dataset_revision은 현재 consent·tombstone·revision을 조회한다. 이를 실행되는 학습 전체의 철회 감시 또는 consent 변경과 학습의 원자적 fence라고 해석할 수 없다. D10의 YAML/manifest 결속 부재 R-D10-003와도 구분한다. 작성자가 F019/F034 notes에 시점 조회와 원자적 fence·학습 중 철회 감시의 차이를 명시했고 재검토했다.
  • R-D10-007의 강제 kill 이후 temporary 잔여 가능성, R-D10-008의 ready와 infer pool 공유, R-D10-011의 PREVIEW 복구 부수효과를 소스로 확인했다. 실제 파일 잔여·동시성 재현·운영 발생 빈도는 시험하지 않았다.
