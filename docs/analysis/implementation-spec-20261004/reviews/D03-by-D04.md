[발견사항과 해결 확인]

1. **문서 오류 — 단계·분기 근거의 자동 배정 불일치.** 최초 F027의 설치/IO 단계가 `RouteScopeDisclosure.kt:1`에 연결되고 F011 watchdog 설명이 Main command binding에 연결되는 등 설명과 원 함수가 달랐다. F031의 `advancePassedGuides`, F034/035의 `observeOffRouteCandidate`, F036의 `observeArrivalCandidate/arrivalDwellMs` 근거도 부족했다. 작성자가 수정한 뒤 선정 8개 단계/분기와 code_refs를 재대조하여 해결을 확인했다. 작성자가 나머지 기능도 고쳤다는 보고는 전수 독립 확인으로 간주하지 않는다.
2. **문서 오류 — gate가 실제 실행 순서에 연결되지 않은 flow.** 최초 도표는 성공 흐름이 decision과 독립되어 실패/취소 경로가 어떤 단계를 막는지 드러나지 않았다. 특히 F028에서 archive 존재를 provenance 검증보다 먼저 결정하는 순서가 실제 `saveFirstRoute:136–145`와 달랐다. 선정 8개 flowchart는 실제 yes/no·실패·stale·retry 흐름으로 수정됐고 provenance 선행 gate를 확인했다.
3. **문서 오류 — LOCATION_RECHECK의 종료 권한 과대 표현.** 중간판 F034는 현재 질문의 종료 선택이 바로 clear로 이어졌다. 실제 `RouteNavigator.kt:792–795`와 `MainActivity.kt:42838` 경로는 confirmed deviation 및 REROUTE를 요구한다. 최종판은 LOCATION_RECHECK 선택을 거절/질문유지로 표시하고 일반 종료를 별도 경계로 연결했다.
4. **문서 누락 — 보호 guide plausibility 임계.** F031의 3단계 증거에 이어 `RouteNavigator.kt:2485–2495`가 요구하는 두 증가 시각, 유한·비감소 guide 거리 및 `min(raw Δt,filtered Δt)×80m/s` 기준이 임계표에 없었다. 최종 input/step/정책/flow에 실제 80m/s와 private const 변경 필요 조건이 반영됐다.

- 위 4건은 **문서 오류 또는 누락**이다. 이번 검토에서 새 제품 결함을 재현했다는 뜻이 아니다.
- 남은 실행 미확인: 실제 FLP/sensor 시간 역전, Activity 및 actor 전환 경합, HTTP/provider 응답, Android keystore/file 실패, TTS DONE/취소 전달, 사용자의 실제 도착 위치.

[실제 수행과 미검토]

- 실제 수행: 고정 snapshot 소스의 위 범위 읽기, 기능/정책/주요 임계와 예외 대조, flow/state 도표 텍스트와 실제 조건 대조, 수정 요청 전달, 최종 SHA 및 11개 도표 해시 확인.
- 테스트: JSON의 TEST_EXPECTATION은 기존 테스트가 선언한 기대다. 이 독립 검토에서는 테스트 본문 전수 감사·테스트 실행·제품 빌드·기기 설치·현장 시험을 하지 않았다. 작성자가 보고한 parser PASS를 제품 동작 증거로 사용하지 않았다.
