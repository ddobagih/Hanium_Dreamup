전체 목차 · 정책 · 추적표

ACTIVE는 코드 연결 확인, CONDITIONAL은 조건부 연결, UNCONNECTED는 호출 연결 미발견, DISABLED는 설정/분기 차단, LEGACY_REFERENCE는 보존 참조, UNKNOWN은 미확인이다. 실제 기기나 운영환경 활성 검증을 뜻하지 않는다.
