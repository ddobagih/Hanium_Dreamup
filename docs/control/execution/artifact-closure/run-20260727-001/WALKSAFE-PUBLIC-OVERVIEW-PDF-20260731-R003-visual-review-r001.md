## 검수 범위와 방법

- 요청된 SHA-256, 파일 크기와 페이지 수를 현재 파일에서 재확인했다.
- 150dpi PNG로 세 페이지를 각각 직접 렌더링하고 전체 페이지와 상·하단 경계를 육안 검수했다.
- 글자 잘림, 요소 겹침, 고아 제목·고아 문장, 페이지 밀도와 공백 균형, 본문 크기, 목록 기호, 푸터 간격과 비전공자 스캔 가능성을 확인했다.
- `pdftotext -layout`로 페이지 경계와 목록의 텍스트 추출을 대조하고, Ghostscript null-page 렌더가 오류 없이 끝나는지 확인했다.
