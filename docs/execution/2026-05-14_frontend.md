## 앱 구조 대조

### fake detector

- `apps/web/types/inference.ts`
  - 클래스 4개: `damaged_tactile_block`, `parked_kickboard_bicycle`, `construction_obstacle`, `pothole`
  - `DetectorSource`: `fake`, `onnx`, `server`
- `apps/web/lib/detector.ts`
  - `createFakeDetection()`이 class id를 `index % 4`로 순환
  - confidence는 0.78, 0.84, 0.90 패턴
  - bbox는 정규화 좌표 사용
  - `source: "fake"` 명시
- `apps/web/app/page.tsx`
  - `NEXT_PUBLIC_DETECTOR_MODE` 기본값은 `fake`
  - `DETECTOR_MODE === "fake"`이고 카메라가 준비되면 2800ms 간격으로 fake detection 생성
  - 화면 문구는 fake일 때 `데모 탐지 모드`, 그 외는 `모델 연결 대기`

판정: 문서 기준과 일치한다. 실제 카메라 프리뷰와 bbox 표시는 브라우저 권한이 필요하므로 수동 검증 대기.

### 신고 API

- `apps/web/.env.example`
  - `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000`
  - `NEXT_PUBLIC_DETECTOR_MODE=fake`
- `apps/web/lib/report-api.ts`
  - API base URL 기본값은 `http://localhost:8000`
  - `checkDuplicateReports()`는 GPS가 있을 때만 `GET /reports/duplicate-check` 호출
  - `submitReport()`는 `metadata` JSON 문자열과 `image` 파일을 `multipart/form-data`로 `POST /reports` 전송
  - `listReports()`는 `GET /reports`
  - `updateReportStatus()`는 `PATCH /reports/{id}/status`
- `apps/web/app/page.tsx`
  - 신고 시 카메라 프레임을 JPEG로 캡처
  - 중복 후보가 있어도 저장 흐름을 막지 않고 상태 문구/TTS로 안내
  - 성공 시 앞 8자리 ID 또는 유사 신고 건수를 표시

판정: 문서 계약과 일치한다. 현재 백엔드가 떠 있지 않아 신고 생성 smoke는 대기.
