- 현재 `runs/validation/` 아래에는 v2 freeze 폴더만 있고 `aihub513_val_links` 또는 `aihub513_official_val_dataset`은 만들지 않았다.

## 남은 일

1. AI Hub 513 validation 실행 허가가 나면 ignored 경로 `runs/validation/aihub513_val_links`, `runs/validation/aihub513_official_val_dataset`를 만들고 외부 validation dataset을 생성한다.
2. 외부 validation dataset 생성 후 `python3 model/validate_yolo_dataset.py --data runs/validation/aihub513_official_val_dataset/data.yaml`를 먼저 통과시킨다.
3. v2 `best.pt`로 AI Hub 513 external validation을 실행하고 recall, mAP50, mAP50-95, confusion matrix를 기록한다.
4. 외부 validation recall이 `0.45` 미만이거나 mAP50-95가 크게 하락하면 v2를 서비스 후보에서 제외하고 v3 실패 프레임 보강으로 넘긴다.
5. 향후 명령은 이 환경에서 `python` 대신 `python3` 또는 명시적으로 활성화된 가상환경의 Python을 사용한다.
