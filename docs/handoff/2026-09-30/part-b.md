담당188개: PARTIAL155 / 미정합33. 분야 S01~S02, S04~S06, S15~S21. [공통 절차](README.md)와 [상세 잔여](remaining-items.json)를 함께 사용한다.

## 파일 소유

Android 사용자 앱의 `voice/**`, `account/**`, `network/**`, `report/**`, `rawcollection/**`, `security/**`, `fieldlog/**`, `debuglog/**`, 최초 실행·동의·삭제·인증 관련 `session` 파일, 관리자 앱, Gateway, Backend, CI·계약·운영·검증 도구를 단독 수정한다.

- A 목록의 보행 session 예외와 `BackendWalkingRouteClient.kt`는 A 소유다.
- navigation 예외 중 `WakeWordController.kt`, `AndroidVoiceCommand.kt`, `VoiceCommandUiDestinationPolicy.kt`, `HomeDestinationVoiceDialogLease.kt`, `DestinationCandidateSpeech.kt`, `DestinationGuidancePresentationPolicy.kt`, `DestinationSearchLocationController.kt`는 B 소유다. 위치 센서 생산자 `AndroidDestinationSearchLocationSource.kt`는 A 소유다.
- 공통 `app/build.gradle.kts`, `AndroidManifest.xml`, 모델 설정·asset 배치·검사 스크립트는 B 소유다. 모델 추론 구현 변경은 A와 맞춘다.
- `MainActivity.kt`는 A가 수정한다. 필요한 연결은 ID·입력/결과 계약·호출 지점·최소 패치·확인 방법을 A에게 전달한다. B의 해당 ID 완료 책임은 유지한다.

## 첫 묶음과 검증

1. **S02-21 + S02-23**: 계정 전환·동의 철회 뒤 신고/수집 소비 경계를 대조하고 A에 Main 연결 패치를 인계한다. 이전 계정 권한으로 다시 전송되지 않는지 검증한다.
2. **S15-8 ↔ A의 S14-31**, **신고 schema ↔ A의 S11-39**: 실제 근거 생산자·허용 항목·동의·전송 계약을 함께 맞춘다.
3. **S01-16 + S19-1**: 장기 로그인·복원·보행 중 갱신을 확인하고 A의 Main 연결 시간을 예약한다.
4. **S04-11 + S04-12**: 음성 입력의 종료·취소와 A의 발화 완료/취소를 연결한다. 이어 **S18-7**은 앱 요청 본문 결속을 먼저 확인하고 서버 필수화·호환 전환을 후속으로 검증한다.

위 순서는 다음 기능 작업 제안이다. 이번 인계에서 이 항목의 반례를 새로 재현하거나 구현을 시작하지 않았다. `S1617-*` 항목은 ID 접두사 대신 상세 목록의 category_id로 16/17을 구분한다.

## 실기기·외부·운영

관리자 앱 실기기, SMTP/TMAP 실제 표본, 전용 PostgreSQL runtime 역할·경합, 프록시·쿠키, 백업·키 회전·복구훈련, CI·배포 증거를 주도한다. 사용자 앱 시나리오는 서버 장애 조건·기대 결과를 준비해 A와 단말 실행을 협업한다. 운영 환경이나 API 성공을 실제 현장 품질 증거로 확대하지 않는다.
