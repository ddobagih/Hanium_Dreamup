# 미학습 객체 영역·깊이 Android 통합 시험 2단계

## 목표

1단계에서 선정한 FastSAM 640을 별도 시험 APK에 넣어 **현재 YOLO26n 768 + FastSAM 640 + ARCore** 실행 비용을 실제 S20에서 측정한다. 작은 분리 마스크 조각 때문에 본체 거리까지 없어지는 문제를 먼저 고친다. 사용자 승인: 1단계 결과 이후 “진행해”. 모델 교체 보류, 현재 앱 보존, 후면 바닥 방향이라는 기존 조건을 유지한다.

이번 산출물은 시험 코드·APK·측정 보고서다. 제품 MainActivity 변경, 움직임 보정, 접근/위험 판정, 음성 안내 통합은 후속 범위다. 의미적 이름이 없는 영역을 찾는 기능을 시험하며, 모든 학습에 없던 객체를 찾는다는 주장으로 확대하지 않는다.

## 정책과 완료 기준

- 전체 마스크 거리 `KNOWN`, 지배 영역만 거리 확인 `PARTIAL`, 거리 `UNKNOWN`을 구분한다. PARTIAL에서는 기존 전체 거리 필드를 null로 두고 확인된 본체 거리와 모든 분리 영역을 함께 반환한다.
- 가장 큰 원래 depth-grid 연결 영역이 전체 면적 80% 이상이고 충분한 깊이가 있을 때만 PARTIAL이 가능하다. 작은 조각 삭제나 가까운 작은 물체 숨김으로 해결하지 않는다. 해당 기준은 재평가 전에 고정한다.
- 프레임 RGB·깊이·confidence·좌표 변환·시각은 같은 불변 snapshot으로 전달한다. 실시간에서는 대기 프레임을 모델별 최신 1개로 제한하고 결과의 처리 완료 시점 나이를 측정한다.
- GPU를 함께 쓴다는 이유로 병렬 방식이 빠르다고 가정하지 않는다. 현재 모델 단독, 두 모델 순차 GPU, 두 GPU 소유 스레드의 동시 실행을 같은 기기 조건에서 비교한다.
- 모델 준비, 전처리, 모델 호출, 마스크 복원, 깊이 연결, 대기, 전체 지연을 구분한다. CPU/GPU 원출력 비교용 고정 입력은 전처리 성능 시험과 구분한다.
- 공개 RGB-D 재생은 정상적인 거리 입력 경로의 검증이다. ARCore의 새 깊이나 실제 물리거리 정답으로 계산하지 않는다. 바닥 방향에서 유효 깊이가 0이면 그대로 보고한다.

## 결과 해석

후보 마스크에 부분 거리가 붙는 비율, 마스크 복원 비용, 기존 검출기의 결과 간격이 추가 모델 때문에 늘어나는 정도를 함께 판단한다. P50/P95 지연, 완료 결과의 나이, 버린 대기 프레임 수, 실제 독립 깊이 관측 수를 보고한다. 4장 정적 재생 반복 횟수는 독립 장면 수가 아니다. 시험 결과에 따라 후속 제품 채택 여부를 판단하며, 이번 문서 자체는 통과 증거가 아니다.


## 실행 중 확인한 문제와 보정

- v4 → v5: GPU 출력 float 단위 읽기를 bulk copy로 바꾸고 중복 유한값 검사를 제거했다. 전처리 scratch와 좌표 계산을 재사용하고, 깊이 정책의 반복 할당·정렬과 좌표 매핑 비용을 줄였다. ARCore YUV plane도 stride를 유지한 bulk copy로 변경했다. 이전 수치와 마스크/깊이 결과의 동일성을 각각 검증했다.
- v5 → v6: 전체 출력의 유한값 검사는 유지하되 Android에서 비용이 큰 표현식을 동치 범위 비교로 바꿨다. NaN/Infinity·정상값·원시 bit pattern과 기존 마스크를 회귀 검증했다.
- v6 → v7: 공개 재생에서도 모델 준비 전에 Activity를 띄워 두 스케줄러 모두 foreground 조건으로 측정한다. 이전 background 공개 시험과 live foreground 시험을 같은 부하로 섞어 해석하지 않는다.
- v7의 10Hz/4장 순환은 latest1 대기열과 주기가 맞물려 FastSAM이 두 장만 선택하는 사례가 발견됐다. 이벤트 수치 자체는 맞지만 네 장 전체 처리의 인수 조건은 실패로 보존한다.
- 최종 비교에서는 동일 네 장을 장면당 50회 입장(약 5초) 동안 유지하는 명시적 재생 옵션을 사용한다. 기존 기본 재생은 그대로 유지한다. 실제 장면별 입장·처리 수, 열 상태와 원출력/깊이 동일성을 독립 검토한다. 두 GPU 스레드에서 처리한 서로 다른 프레임 수를 합산해 결합 FPS로 만들지 않는다.

실행 세부 지연은 측정 구간에 입장한 모든 작업(구간 뒤 완료 포함), 처리량은 구간 안에 완료한 작업으로 집계한다. 모델 결합 결과는 실제 채택 결정 시점의 나이로 검사한다. 고정 1초 컷오프는 이 실험의 신선도 기준이며 제품의 보행 안전 임계값이 아니다. 시험용 주성분 마스크의 PARTIAL은 깊이 격자에 매핑된 영역에 한정한다. snapshot 배열은 소유권 분리 후 읽기 전용으로 다루는 계약이며 JVM에서 불변을 강제하는 타입은 아니다.
