## 2. 회원가입 첫 화면

### 화면 제목

> WalkSafe를 시작하기 전에 확인해 주세요

### 본문

> WalkSafe는 보행 중 카메라와 위치를 이용하는 안전보조 서비스입니다. 모든 위험을 찾거나 사고를 막는 것을 보장하지 않으며, 긴급한 상황에서는 112 또는 119에 직접 연락해야 합니다.<br>
> 현재는 만 14세 이상만 가입할 수 있습니다. 입력한 생년월일을 기준으로 서버가 만 14세 이상인지 계산합니다. 이 절차는 휴대폰·PASS 본인확인, 실명·명의 확인 또는 공적 연령 인증이 아닙니다.<br>
> 가입 인증번호는 입력한 이메일 주소로 발송됩니다.

### 입력과 버튼

- `이메일 주소`
- `생년월일`
- `이메일 인증번호 받기`
- `기존 계정 로그인`
- `나중에 하기`

`만 14세 이상이면 누르세요`처럼 답을 유도하는 문구, 필요한 나이가 드러나는 선택지 또는 기본 선택된 생년월일은 사용하지 않는다. 다만 자유 입력 생년월일만으로 실제 연령을 확인하는 현재 방식의 충분성은 **NOT_APPROVED**이다. 개인정보보호위원회는 생년월일 입력만 두었던 사업자에게 실제 나이를 확인할 수 있는 방법을 추가하도록 개선 권고한 사례가 있다. Google Play의 중립적 연령 화면 원칙도 플랫폼 정책일 뿐, 현 방식의 법적 적정성이나 이용자 신원을 보증하지 않는다. [개인정보 보호법 제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523), [개인정보보호위원회 의결·개선 권고 사례](https://www.pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=8776), [Google Play 연령 심사 안내](https://support.google.com/googleplay/android-developer/answer/9867159?hl=ko)

## 3. 생년월일 연령 검사·이메일 OTP 고지

### 이메일 인증번호 요청 전

> **가입 가능 연령과 이메일 수신 여부를 확인합니다**<br>
> 입력 항목: 이메일 주소, 생년월일<br>
> 목적: 입력한 생년월일을 기준으로 만 14세 이상 여부를 계산하고, 가입용 6자리 인증번호를 입력한 이메일로 보내기 위함<br>
> 처리 방식: 서버는 대한민국 표준시의 날짜를 기준으로 만 14세 이상 여부를 계산합니다. 현재 방식은 사용자가 입력한 값만 검사하며 신원·실명·명의 또는 공적 연령을 인증하지 않습니다.<br>
> 이메일 발송자: `[NOT_APPROVED: SMTP 서비스/수탁자·sender]`<br>
> 처리 국가와 위탁·국외이전: `[NOT_APPROVED: 국가·법적 역할·고지/동의 내용]`<br>
> 기술상 저장: 원문 생년월일은 enrollment DB 열에 저장하지 않지만, 이메일과 생년월일에 결합된 요청 HMAC을 저장합니다. 이메일은 암호화본과 조회용 HMAC으로, 인증번호는 HMAC으로 저장합니다.<br>
> 유효시간: 현재 가입 인증번호 기본 10분(설정 가능 최대 30분)<br>
> enrollment·발송 로그 보유기간: `[NOT_APPROVED: 만료·성공·취소별 기간과 파기 주기]`<br>
> 거부 효과: 이메일 주소 또는 생년월일을 제공하지 않으면 계정을 만들 수 없습니다.

이메일 OTP는 해당 이메일 받은편지함에 접근할 수 있음을 확인할 뿐이다. 이메일 명의, 실명, 휴대전화 명의 또는 공적 연령을 확인하지 않는다.

### 만 14세 미만 결과

> **가입을 진행할 수 없습니다**<br>
> 현재 WalkSafe는 만 14세 미만 회원가입과 법정대리인 동의 가입을 지원하지 않습니다. 가입 인증번호와 enrollment·계정은 생성되지 않습니다.

서버가 연령 조건을 통과시키기 전에 OTP 또는 계정 레코드를 생성하지 않는다는 뜻이다. 요청 전달 계층이나 보안 로그에 원문 요청이 남지 않는다고 단정하지 않으며, 그 로그 항목과 보유기간은 `[NOT_APPROVED: Gateway·Backend·보안 로그 정책]`에서 확정한다.

### 이메일 인증 실패·취소

> **이메일 인증을 완료하지 못했습니다**<br>
> 계정은 생성되지 않았습니다. 이메일 주소와 6자리 인증번호, 인증번호 유효시간을 확인한 뒤 다시 시도해 주세요. 문제가 계속되면 `[NOT_APPROVED: 고객지원 연락처]`로 문의해 주세요.

### 인증 성공 후 계정 생성

> 6자리 이메일 인증번호를 확인한 뒤 비밀번호로 계정을 만듭니다. 비밀번호 원문은 저장하지 않고 scrypt digest를 저장합니다. 이메일은 암호화본과 조회용 HMAC으로 저장합니다.

현재 순서는 `이메일·생년월일 입력 및 필수 항목 선택 → 6자리 OTP 발송 → OTP·비밀번호 제출 → 계정 생성 → 로그인 완료 → 기기점검 gate`이다. 가입 전용 enrollment credential은 계정이나 로그인 session을 요구하지 않아야 하며, OTP 검증·계정 생성에만 제한해 순환 의존을 만들지 않는다.

## 4. 회원가입 동의 화면

### 공통 안내

> 필수 항목은 현재 구현에서 계정 생성과 핵심 서비스 제공을 위해 요구합니다. 선택 항목은 모두 거부해도 가입할 수 있으며, 해당 자료가 필요한 기능만 제한됩니다. 각 문서를 열어 목적·항목·보유기간·거부 효과와 철회 방법을 확인할 수 있습니다.

### 체크 항목

1. `[필수] 서비스 이용약관에 동의합니다.`
2. `[필수] 개인정보 처리 내용을 확인했습니다.`<br>
   - 동의를 법적 근거로 삼는 처리는 `확인`으로 갈음하지 않고 목적·항목·보유기간·거부 효과를 제시한 `[필수] 수집·이용 동의`로 분리한다.
3. `[필수] 위치기반서비스 이용약관에 동의합니다.`<br>
   - 현재 코드는 필수로 검사한다. WalkSafe의 위치기반서비스사업 해당 여부와 가입 단계 필수 처리의 법적 적정성은 `[NOT_APPROVED: 위치정보 법률 검토 결과]`이다.
4. `[선택] 신고·진단용 raw v2 자료 처리에 동의합니다.` 기본 OFF
5. `[선택] 조건 충족 시 자동신고에 동의합니다.` 기본 OFF
6. `[선택] 사람이 승인한 비식별 자료의 AI 개선·학습 활용에 동의합니다.` 기본 OFF

OTP 요청 전에는 앱이 필수 3개를 확인하지만 OTP 요청 payload에는 동의값이 없고, 서버는 이메일·생년월일 형식과 연령 조건을 검사한다. OTP·비밀번호로 계정을 생성할 때 앱과 서버가 필수 3개를 다시 확인하고 가입 동의 receipt를 남긴다. 선택 3개는 각각 분리하고 기본값을 OFF로 두며, 전부 거부해도 OTP 요청과 계정 생성을 허용한다. 현재 자동신고는 4번의 신고·raw 자료 처리 동의와 5번 자동신고 동의가 모두 있어야 동작한다.

`모두 동의`를 제공한다면 필수와 선택이 함께 켜진다는 사실을 명확히 알리고 선택 항목을 개별적으로 다시 끌 수 있게 한다. 이동통신망 사용 여부는 개인정보 동의와 합치지 않고 별도 설정으로 둔다.

> **이동통신망으로 신고 전송 허용**<br>
> 끄면 신고는 Wi‑Fi 연결 때까지 기기에 암호화해 보관합니다. 보관 한도나 만료로 전송하지 못할 수 있으며, 긴급 신고를 대신하지 않습니다.

## 6. 선택 동의 상세 문안

### 6.1 신고·진단용 raw v2 자료 처리

> **[선택] 신고·진단용 raw v2 자료 처리**<br>
> 목적: 안전기능 탐지·성능 상태의 확인과 품질 진단<br>
> 현재 항목: DETECTION metadata(구간·capture 시각, 처리 frame 수, 탐지 수, 평균 inference 시간, detector 사용 가능 여부, model revision)와 PERFORMANCE metadata(처리·drop frame 수, 평균 frame 시간, thermal throttling 여부), chunk 시각·크기·hash<br>
> 현재 제외: 영상, 음성, 이미지, 정확한 위치, 이동 경로, 개별 frame·bbox는 active raw v2 경로에서 수집·업로드하지 않음<br>
> 기기 저장: 보행 ACTIVE 중 동의와 조건을 확인해 암호화 저장하며, 단말 기술상 TTL은 최대 30일<br>
