1.1시스템의 개요

본 시스템은 시각장애인이 일반 도심 보도를 걸을 때, 화면을 계속 확인하지 않고도 가까운 위험과 큰 이동 방향을 알아차릴 수 있도록 돕는 Android 보행 보조 서비스이다. 휴대전화를 가슴 또는 목걸이형 거치대에 고정하면 후면 카메라가 앞을 보고, 앱은 촬영한 영상을 휴대전화 안에서 분석해 앞에 있는 물체와 그 거리를 판단한다. 판단 결과는 짧은 한국어 음성과 구별 가능한 진동으로 전달하며, 사용자는 화면을 보거나 누르지 않고 호출어와 음성 명령으로 앱을 조작한다.

길안내는 TMAP 보행 경로를 사용한다. 목적지를 말하면 후보를 음성으로 읽어 주고, 사용자가 번호로 고르면 경로 전체를 휴대전화에 저장한 뒤 회전과 남은 거리를 안내한다. 경로를 벗어나면 오래된 안내를 멈추고 새 경로 요청·위치 다시 확인·길안내 종료 중 하나를 사용자가 고르게 한다. 점자블록은 지도 경로를 바꾸는 기준이 아니라 그 경로 안에서 같은 방향으로 이어지는 구간을 보조하는 신호로만 쓴다.

또한 보행 중 발견한 손상된 점자블록을 신고 후보로 남긴다. 신고는 보행 중에 전송하지 않고 보행이 끝난 뒤 허용된 통신 조건에서 서버로 보내며, 지정 관리자가 검수한 뒤 책임 기관에 전달한다. 이는 한 사람의 보행을 돕는 데 그치지 않고 보행 환경 자체를 고치는 데 기여하기 위한 것이다.

본 시스템은 사용자의 안전을 보장하지 않으며 흰지팡이나 안내견을 대신하지 않는다. 모든 장애물을 인식하지 못할 수 있고 위치와 거리에 오차가 있을 수 있다. 따라서 안전하지 않은 안내를 계속하는 것보다, 이유를 알리고 관련 기능 또는 전체 보행 기능을 멈추는 것을 우선한다. 이 원칙이 이후 모든 요구사항의 바탕이 된다.

구성

사용자용 Android 앱과 관리자용 Android 앱을 분리하여 제공한다. 관리자 앱은 비공개로 배포하며 지정 관리자 한 명이 비밀번호와 TOTP로 인증한 뒤 신고 검토, 기관 전달 이력, 감사·보안, 개인정보·원본 처리에 사용한다. 두 앱의 모든 서버 요청은 사용자 Gateway를 지나 FastAPI Backend로 중계되며, 계정·신고·위치·변경 이력은 PostgreSQL/PostGIS에, 신고 이미지와 원본 파일은 암호화된 별도 저장소에 둔다. 목적지 검색과 보행 경로는 외부 TMAP API를, 가입 인증번호는 SMTP 메일을 사용한다. 음성은 기능에 따라 단말 인식과 서버 음성 서비스를 나눠 쓰되, 호출어와 위험·길안내 음성은 네트워크 없이 단말에서 처리한다. 과거 웹 버전은 개발 참고 기록으로만 보존하고 외부에서는 실행할 수 없게 한다.

1.2목표

  • 화면을 보지 않고 끝나는 보행 보조 가입·동의·권한·보행·오류 대응까지 핵심 절차를 화면을 확인하지 않고 완료할 수 있게 한다. 전맹과 저시력 사용자를 같은 우선순위로 두고, 한 집단만 통과한 기능을 접근성 완료로 보지 않는다.
  • 판단을 대신하지 않는 안내 위험을 확정하거나 안전을 보장하지 않는다. 관찰한 것을 일관된 방식으로 전달하고 최종 행동은 사용자가 고른다. 피할 공간의 안전을 따로 확인하기 전에는 좌우 이동을 지시하지 않고 "멈추세요. 주변을 확인하세요."로 제한한다.
  • 할 수 있는 만큼만 약속하는 기기 판정 기기 이름이 아니라 필요한 기능을 실행 시점에 실제로 검사해 전체 기능·거리 제한·사용 불가로 나눈다. 거리를 잴 수 없는 기기에서 거리나 충돌 시점을 추측해 말하지 않고, 제한 상태를 알리지 않은 채 정상 기능처럼 시작하지 않는다.
  • 보행 환경 자체의 개선 손상된 점자블록을 신고 후보로 모아 관리자 검수를 거쳐 책임 기관에 전달한다. 한 사람의 이번 보행을 돕는 것을 넘어, 다음 사람이 걸을 길을 고치는 데 기여한다.
