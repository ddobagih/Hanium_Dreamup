# WalkSafe 음성 발화와 검증표

기준일: 2026-09-06

이 문서는 명령 해석기 캐시와 이번 자연어 확장, 공개 장소를 사용한 POI 비교 결과를 바탕으로 작성했다. 소스를 다시 읽거나 제품 코드를 변경하지 않았다. 앱 전체 음성 입력부터 실제 동작과 음성 출력까지의 E2E 완료 보고서는 아니다.

## 1. 확인 수준

| 표시 | 의미 |
| --- | --- |
| 구현 확인 | 명령 해석기에 해당 처리와 회귀 테스트가 추가되어 있다. 실제 휴대전화에서의 인식 성공을 뜻하지 않는다. |
| 실제 API 확인 | 앱과 음성 인식을 거치지 않은 공급자 직접 요청 결과다. |
| 미검증 | 이 문서 작성 과정에서 실행하지 않았다. 최종 통합 검증 결과와 별도로 확인해야 한다. |
| 미확인 | 현재 캐시만으로 정확한 지원 문구나 동작을 확정할 수 없다. |

자연어 확장 회귀 테스트는 5개 추가했다. 이 문서 작성자는 해당 테스트 실행, Gradle, ADB, 실기기 검증을 수행하지 않았다.

## 2. 목적지 검색에 사용할 수 있는 말

아래는 구현 확인 범위다. 음성 인식기가 문장을 올바르게 전달했을 때 장소 부분을 검색어로 분리한다.

| 발화 예시 | 전달할 검색어 | 주의점 |
| --- | --- | --- |
| 금오공대 목적지로 해줘 | 금오공대 | 이 말만으로 목적지 확정이나 보행 안내가 시작되지 않는다. |
| 금오공대 목적지로 해 줘 | 금오공대 | 띄어쓰기 변형을 처리한다. |
| 금오공대목적지로해주세요 | 금오공대 | 붙여 말한 인식 결과도 처리한다. |
| 금오공대 가고 싶어 | 금오공대 | 검색 요청으로 해석한다. |
| 금오공대 가고싶어요 | 금오공대 | 검색 요청으로 해석한다. |
| 시립 도서관 가고 싶습니다 | 시립 도서관 | 장소 이름 안의 공백을 유지한다. |
| 편의점 찾아줘 | 편의점 | 실제 현재위치 중심 검색과 후보 지역은 별도 확인해야 한다. |
| CU 편의점 찾아 주세요 | CU 편의점 | 영문 상호의 대소문자를 유지한다. |
| 금오공대 안내해줘 | 금오공대 | 조사 없는 안내 요청도 검색으로 연결한다. |
| 시립 도서관 안내 해 주세요 | 시립 도서관 | 검색 요청으로 해석한다. |
| 금오공대로 안내해줘 | 금오공대 | 기존 조사형 처리 계약을 유지한다. |
| 학교로 안내해줘 | 학교 | 기존 조사형 처리 계약을 유지한다. |
| 종로 찾아줘 | 종로 | 새 검색형에서는 장소 이름의 끝 글자를 유지한다. |

특정 문장 한 가지만 외울 필요는 없지만, 모든 자유로운 말투를 이해하는 기능은 아니다. 학교별 약칭 변환, LLM 해석, 추측한 장소 자동 확정은 추가하지 않았다.

## 3. 검색 후 반드시 확인할 것

1. 앱이 인식한 장소가 말한 장소와 같은지 확인한다.
2. 검색 후보의 이름과 지역을 확인한다. 학교 이름으로 검색해도 운동장, 기숙사, 출입구 등 부속 시설이 나올 수 있다.
3. 후보가 여러 개면 원하는 후보를 명시적으로 선택하고 확인한다. 명령 해석 결과는 `SearchDestination`이며 후보를 자동 확정하지 않는다.
4. 검색 성공과 실제 보행 안내 시작을 구분한다. 검색용 위치를 얻었다고 경로 시작이나 경로 안전성이 검증된 것은 아니다.

후보 선택 음성 문구, 안내 시작, 취소, 정지, 신고의 정확한 허용 문구 전체는 이 문서의 캐시 범위로 확정하지 않는다. 화면 안내와 최종 실기기 검증으로 확인해야 한다.

## 4. 실기기 확인표

다음 항목은 모두 미검증이다. 시험 결과에는 인식된 문장, 보이는 상태, 후보 지역, 실제 동작, 음성 출력 여부를 구분해 기록한다. 개인 좌표와 계정 정보는 기록하지 않는다.

| 시험 | 수행 방법 | 통과 기준 | 상태 |
| --- | --- | --- | --- |
| 실제 사용자 발화 | 음성 입력을 시작하고 "금오공대 목적지로 해줘"라고 말한다. | 장소 검색으로 연결되고 인식 결과에서 목적지 문구가 검색어에 섞이지 않는다. 자동 확정하지 않는다. | 미검증 |
| 다른 말투 | 같은 장소에 "가고 싶어", "찾아줘", "안내해줘"를 각각 사용한다. | 장소 검색으로 연결되며 서로 다른 의도로 오인 실행하지 않는다. | 미검증 |
| 현재 지역 검색 | 정상 권한과 위치 서비스 상태에서 "편의점 찾아줘"라고 말한다. | 실제 현재 지역의 후보인지 확인한다. 공개 시험 좌표나 고정 서울 좌표를 현재위치로 사용하지 않는다. | 미검증 |
| 후보 선택과 확인 | 복수 후보에서 의도한 장소를 선택한다. | 선택 전에는 목적지가 확정되지 않고 선택한 이름과 지역을 확인할 수 있다. | 미검증 |
| 오인식 후 재시도 | 인식된 장소가 다르면 후보를 확정하지 않고 음성 입력을 다시 시작한다. | 두 번째 검색어로 새 결과가 표시되고 이전 후보가 새 결과처럼 남지 않는다. | 미검증 |
| 무응답 후 재시도 | 입력 실패나 응답 없음 상태를 확인한 뒤 음성 입력을 다시 시작한다. | 실패나 대기 상태를 알 수 있고, 이후 요청이 영구적으로 막히지 않는다. | 미검증 |
| 연속 두 번 호출 | 첫 요청이 완료된 뒤 다른 장소로 음성 입력을 한 번 더 시작한다. | 첫 번째와 두 번째 모두 입력, 동작, 출력이 완료된다. 이전 응답이 두 번째 화면을 덮지 않는다. | 미검증 |
| 음성 출력 실패 | 시험 환경에서 음성 출력 실패 상황을 확인한다. | 기존 상태 표시로 실패를 알 수 있고 검색 결과를 가리지 않는다. 텍스트 표시와 실제 발화를 따로 판정한다. | 미검증 |
| 위치 재획득 실패 | 새 검색에서 위치 획득이 실패한 상황을 시험한다. | 현재위치 사용 불가와 재시도 상태가 분명하며, 이전 후보를 새 검색 결과로 오해하게 하지 않는다. | 미검증 |
| 화면 이탈 후 재진입 | 검색 중 뒤로 이동하거나 앱을 배경으로 보낸 뒤 다시 검색한다. | 이전 요청이 현재 화면을 덮지 않고 새 요청을 시작할 수 있다. | 미검증 |

실제 신고나 기관 전송을 발생시키는 시험은 이 확인표에 포함하지 않는다. 보행 중 화면 조작으로 시험하지 않는다.

## 5. 해석 단계의 거절과 남은 경계

다음은 코드와 추가 회귀 테스트에서 의도한 거절 동작이다. 실제 음성 인식부터 실행까지의 안전성 검증이 완료되었다는 뜻은 아니다.

| 입력 | 해석 단계 기대 동작 |
| --- | --- |
| 목적지로 해줘 / 찾아줘 / 가고 싶어 / 안내해줘 | 장소가 없으므로 동작하지 않는다. |
| 편의점 찾아주지 마 | 부정문으로 거절한다. |
| 금오공대 목적지로 하지 마 | 부정문으로 거절한다. |
| 서울역 안내해줘 찾아줘 | 중첩된 명령을 장소 이름으로 전달하지 않는다. |
| 신고해줘 그리고 편의점 찾아줘 | 복합 위험명령을 임의 실행하지 않는다. |
| 신고센터 찾아줘 | 장소 검색으로 처리하며 단어의 부분 일치로 신고를 실행하지 않는다. |

- 낮은 인식 신뢰도와 후보 명시 선택은 별도 조건이다. 이해되지 않은 문장을 추측해 자동 실행하는 기능은 추가하지 않았다.
- "종로 안내해줘"처럼 장소 끝 글자와 방향 조사 "로"가 겹치는 기존 경계는 이번 최소 패치에서 해결하지 않았다. 이 경우 "종로 찾아줘" 또는 "종로 목적지로 해줘"처럼 명확한 검색형을 사용한다.
- 전체 자유문장, 복합 요청, 정확한 음성 호출어, 취소 후 자동 재청취 여부는 미확인이다.
- 검색용 위치, 실제 경로 시작 위치, 보행 안전 판정은 서로 다른 확인 항목이다. 실제 보행과 경로 안전 검증은 `NOT_RUN`이다.

## 6. "금오공대" 약칭의 실제 검색 근거

앱, ASR, 명령 해석기를 거치지 않고 공식 POI API를 총 2회 호출했다. 두 요청 모두 같은 공개 서울시청 기준점과 전국 범위의 거리순 조건을 사용했다. 이 기준점은 비교용 synthetic 입력이며 사용자 현재위치가 아니다. [공식 POI 요청 규격](https://tmap-skopenapi.readme.io/reference/장소통합검색)

| 검색어 | HTTP | 공급자 총건수 | 상위 3개 후보 |
| --- | --- | --- | --- |
| 금오공대 | 200 | 97 | 금오공과대학교 테니스장, KIT교직원아파트, 국립금오공과대학교 운동장 |
| 금오공과대학교 | 200 | 63 | 금오공과대학교 테니스장, 국립금오공과대학교 운동장, 국립금오공과대학교 오름관1동 |

상위 후보는 모두 경북 구미시였다. 이 조건에서는 공급자의 약칭 검색 0건이 재현되지 않았다. 사용자가 겪은 0건의 전체 원인을 확정한 결과는 아니며, 특정 학교 별칭 하드코딩이나 첫 번째 후보 자동 확정의 근거로 사용하지 않는다.

응답 원문은 헤더 없이 별도 비공개 파일에 보관했으며, 키와 사용자 위치를 이 문서에 저장하지 않았다. 최종 통합 검증과 daylog는 주 담당자가 별도로 취합한다.
