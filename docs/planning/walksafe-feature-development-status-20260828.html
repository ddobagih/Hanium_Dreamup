코드·테스트·최근 작업 기록을 대조한 현재 기준입니다.

결정: 개발 중 제어 자동화는 중단

체크포인트 sequence 변경, 코드 해시 봉인, 검토 라운드, Goal 상태 전환 자동화는 더 진행하지 않는다.

  • 기존 기록은 삭제하거나 덮어쓰지 않고 과거 기록으로만 보존한다.
  • 기능 개발 중에는 일반 단위·기능·통합 테스트와 간단한 daylog만 사용한다.
  • 모든 로컬 기능이 완성된 뒤 출시 후보를 고정할 때만 제어 자동화를 다시 검토한다.
  • cloud·정식시험·실운영 증거는 최종 완성 뒤 Wave 5에서 만든다.

이 결정은 기존 로컬 실행 계획의 seq100/101/102 제어 작업보다 우선한다.

이미 로컬 구현된 기능

보안·서버 기능

  • 개인정보 요청 오류 수정과 계정 삭제 API 경로 연결
  • 서버 신고자료 실제 삭제 one-shot과 최소권한 역할
  • 서버 용량 상태의 Backend → Gateway → Android 전달
  • readiness, 내부 health, 제한 telemetry, 백업·복원 실행 틀
  • 7종 암호화 상태의 일괄 키 회전

Android 사용자 기능

  • 경로 이탈 감지와 사용자 선택형 재탐색
  • TMAP·GPS·진행방향·보폭 책임 분리
  • 점자블록은 신뢰 가능한 TMAP 경로에서만 보조
  • 오프라인 TTS 실패 시 안전정지
  • 권한·장애 발생 시 접근 가능한 종료·설정·재검사 화면

남은 실제 기능과 구현 순서

순서기능현재 상태남은 구현
1 위험안내 안전 계약
FP-020		 부분 구현 STOP 문구를 “멈추세요. 주변을 확인하세요.”로 고정하고 WARNING 고유 진동을 추가한다. 현재 코드와 요구사항이 직접 충돌하므로 가장 먼저 수정한다.
2 탐지·거리·카메라 품질
FP-019·021		 부분 구현 승인 모델·class allowlist 결속, 불확실 후보 무안내, 반복 실패 안전정지, 밝기·가림·흔들림·장착각·신선도와 탐지 후 거리·신뢰도 gate를 한 pipeline으로 마무리한다. 운영 임계값 승인은 실기기 시험 뒤로 둔다.
3 음성 명령·접근성 완결
FP-025·026·028·030		 부분 구현 버튼식 1회 인식에 더해 “길라잡이” 호출어와 듣기 시작·끝 신호를 구현한다. 빠진 pause/resume 및 비가역 명령 확인, 전체 화면의 읽기 순서·포커스·큰 글자·대비·터치영역을 완결한다.
4 원본자료 수집·보존·삭제
EPIC-07		 핵심 미구현 영상·음성·정확 위치·센서·경로·탐지·신고·성능의 공통 manifest/chunk, 단말 암호화 append 저장소, 서버 checksum·멱등 수신·검역, receipt 뒤 단말 삭제, 저장소별 보존·삭제를 구현한다.
5 자동신고 암호화 대기열
EPIC-08		 핵심 미구현 현재 꺼져 있는 영속 queue를 구현한다. 보행 중 전송 금지, 종료 뒤 허용한 통신망에서만 전송, 재부팅 복구, 30일·byte 상한, 멱등 재시도, 서버 receipt 뒤 단말 사본 삭제를 연결한다.
6 기기 자원·중앙 안전정지
EPIC-09		 부분 구현 저장공간·배터리·발열·카메라 신선도·추론 지연을 감시하고, 안전 핵심 장애는 전체 정지하며 자료 전송 장애만 조용히 보류하도록 통합한다.
7 모델·앱·설정 수명주기
EPIC-10·11		 부분 구현 데이터 출처·동의·철회, 독립 평가, 승인 모델·앱·설정 묶음, 이전 정상판 복구와 단계 업데이트를 출시 후보 단위로 완성한다.
