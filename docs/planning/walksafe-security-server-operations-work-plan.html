운영 준비

  • EPIC-09는 EPIC-03·07·08이 완료·결속돼야 합니다.

  • 현재 저장소의 전역 focus는 EPIC-04이며, ready frontier는 EPIC-04·12입니다. 따라서 EPIC-07·09·11의 제품 코드 시작은 Goal 상태와 팀 우선순위를 먼저 전환한 뒤 진행합니다.

모든 기능에 적용할 작업 루프

  1. 실패 조건부터 고정 — 권한 우회, 부분 저장, 재시도, 용량 초과, 복원 같은 부정 경로 테스트를 먼저 작성합니다.
  2. 계약과 경계 확정 — API/schema/state/TTL/idempotency/감사 필드를 문서와 테스트에 결속합니다.
  3. 최소 구현 — 해당 계약을 만족하는 서버·저장·운영 코드만 구현합니다.
  4. 구성요소·통합 검증 — 정상/실패/재시작/중복/부분장애를 재현하고 기존 안전 기능 회귀를 확인합니다.
  5. 증거와 인계 갱신 — RTM, test result, runbook, receipt를 남기고 실제 기기·운영·외부 검증은 승인된 gate로 넘깁니다.
