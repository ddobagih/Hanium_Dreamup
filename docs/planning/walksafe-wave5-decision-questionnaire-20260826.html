Wave 5A부터 5G까지 필요한 결정을 쉬운 질문으로 모았습니다. 모르는 항목은 “비교안 필요”를 선택하면 되고, 비밀번호·API 키·인증서 원문은 절대 적지 않습니다.

오프라인 단일 HTML 브라우저 자동 저장 JSON 내보내기·불러오기 작성 ≠ 배포 승인
진행률 계산 중 저장된 답변을 확인하고 있습니다.

먼저 확인하세요

입력 금지: 비밀번호, API key/token, private key, 인증서 원문, 결제계정 번호, 개인 전화번호·개인 이메일, 실제 사용자 개인정보. 담당자는 ops-primary, 연락처는 #walksafe-incident 같은 역할·채널 별칭만 적으세요.

답변은 브라우저 저장소에 저장되고 내보낸 JSON은 암호화되지 않은 평문입니다. 민감정보 탐지는 보조 기능일 뿐 전부 찾아내지는 못합니다. 공용 PC에서 작성하지 말고, JSON은 Git 저장소 밖의 접근 제한·암호화 위치에 보관하세요. 브라우저별 자동 저장·인쇄 동작도 다를 수 있습니다.

이 문서의 권한 경계

이 HTML은 Wave 5 준비 입력을 모으는 비정본 작업 문서입니다. 답변 완료·자동 저장·JSON 내보내기는 정책 변경, cloud 자원 생성, 비용 발생, 외부 데이터 전송, 정식시험 PASS, gate 종결, staging·production 배포, public ingress 활성화 또는 출시 승인을 뜻하지 않습니다.

GCS 서울 리전이라는 정책 방향도 GCP 계약·개인정보 처리위탁 검토가 끝났다는 뜻은 아닙니다. 실제 계약과 적용성은 Wave 5 실행 중 별도 증거로 확인합니다.

답변 초안의 [추가 결정 필요] 표시는 값이 입력되어 있어도 완료가 아니라 협의 필요로 계산됩니다.

선택하지 않는 고정 기준

아래 값은 승인된 정책 또는 현재 사실입니다. 다르게 가려면 질문지 답변이 아니라 별도 정책 변경·재승인이 필요합니다.

저장소와 지역

Google Cloud Storage, asia-northeast3(서울)

용량 기준

주 원본 Standard 300GiB + 백업 Nearline 300GiB

백업 보존

35일 순환. 운영과 분리된 환경에서 실제 복원해야 함

자료 보존·삭제

수신·검역 14일, 일반·자동신고 원본 180일, 승인 학습자료 3년. 삭제요청은 서버 7일·가공본 30일

저장비 안전상한

저장·요청·복원 비용 합계 최대 월 30,000원. 지출 승인이 아니며, 전체 예산을 0원으로 답하면 더 엄격한 0원 기준이 적용됨

서버 용량 단계

주 원본 70·85·95·100% 단계 고정. 휴대전화 byte 상한은 별도 실기기 측정 gate

제품 경계

사용자 Android 앱 + 비공개 등록기기용 관리자 Android 앱 + Gateway + Backend. Web/PWA는 운영 대상 아님

앱 배포 경계

사용자 앱은 Google Play, 관리자 앱은 등록된 관리자 기기에만 비공개 배포

정식시험

총 279건: 기능 123, 장애·복구 46, 실기기·현장 54, API·통합 32, 접근성·사용성 15, 기타 9

출시 gate

5개 모두 실제 실행·독립 판정, waived=false. 279건 안의 case PASS만으로 자동 종결되지 않음

실패와 최종 권한

필수 FAIL·NOT_RUN은 severity와 무관하게 차단. 최종 관리자·출시 승인자는 1명이며 부재 시 고위험 변경·출시 동결

배포 순서

비공개 검증 → GO 판단 → staging → production canary. 삭제 scheduler는 마지막

지원 기본시간

평일 09:00~18:00 Asia/Seoul. 시간 외 운영에는 자동 안전조치와 지정 비상대응자가 필요

현재 상태

정식시험 0/279, gate 0/5, 배포 사건 0, release NOT_ELIGIBLE

Wave별 바로가기

이 질문지를 다 쓰면

  • 답변 JSON을 내보내 Git 저장소 밖의 접근 제한·암호화 위치에 둡니다. 메신저·이메일로 보내지 않습니다.
  • 답변은 구현·견적·권한 요청의 입력입니다. 답변만으로 cloud 생성, 배포, 시험 PASS 또는 출시 승인이 되지 않습니다.
  • 실제 자원 ID·명령·hash·시험 결과·승인은 실행하면서 별도 추가 전용 기록으로 남깁니다.
  • 현재 작업 종료·변경 권한 정합화와 정식 Goal/focus·Wave 5 start gate 승인을 모두 확인한 뒤에만 Wave 5A 인프라/IaC와 fail-closed preflight를 구현합니다.
