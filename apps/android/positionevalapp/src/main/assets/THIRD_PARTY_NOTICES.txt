WalkSafe Position Evaluator - bundled components
================================================

Bundled dependency
------------------

Apache Commons Compress 1.27.1
Upstream: https://commons.apache.org/proper/commons-compress/
License: Apache License 2.0

Used only to decode the traditional Unix compress `.Z` files published by the
NGII hourly RINEX directory. The dependency JAR carries its upstream LICENSE
and NOTICE metadata. The fixed `bla.tar.Z` byte fixture embedded in
`ArchiveValidationTest` is from the same Apache Commons Compress project and is
covered by the same Apache License 2.0.

The components below are pinned, bundled into the application build, and
executed by the analysis pipeline. Runtime version and validation gates remain
fail-closed if a pin does not match.

RTKLIB-EX (formerly demo5) v2.5.1
Upstream: https://github.com/rtklibexplorer/RTKLIB
Commit: 62d4677ed8425a4e2748c6d390b500d1afb493fc
License: BSD-2-Clause

The pinned RTKLIB-EX sources are compiled into the arm64-v8a JNI library. The
application invokes postpos() for multi-hour base observation and navigation
inputs and accepts only Q=1 FIX epochs for evaluation.

Upstream: https://github.com/rtklibexplorer/android_rinex
Commit: b27fcd07bc085e5213ba29655ad6168b61d60b9e
License: BSD-2-Clause

The application includes a Kotlin GnssLogger TXT to RINEX3 converter derived
from the pinned measurement equations and signal mapping. Its output is gated
by Android GNSS regression tests and an RTKLIB readrnxt round-trip test.
