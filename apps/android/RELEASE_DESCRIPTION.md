# WalkSafe Android 릴리스 설명 후보

> 문서 상태: `INTERNAL_DRAFT_NOT_PUBLISHED`  
> 연계 산출물: `REL-09 릴리스 노트`  
> 산출물 상태: `PLANNED/NOT_RUN`  
> 출시 상태: `NOT_ELIGIBLE`

이 문서는 향후 릴리스 설명에 사용할 수 있는 내부 문안 후보입니다. 실제로 게시하거나 배포한 릴리스 노트가 아니며, `REL-09`의 상태를 변경하지 않습니다.

## 소개 문안 후보

워크세이프는 시각장애인의 도심 보행 중 가까운 위험과 이동 방향을 알려 주고 손상 점자블록 신고를 돕는 안드로이드 보행 보조 서비스입니다.

워크세이프는 보행 안전을 보장하지 않으며 흰지팡이·안내견·보호자를 대신하지 않습니다.

## 이 후보가 다루는 기능 범위

- 휴대전화 카메라와 기기 내 인공지능 모델을 이용한 가까운 위험 안내
- 사용자가 선택한 목적지에 대한 TMAP 큰 이동 방향 안내
- 별도 자료 동의와 위치·중복 조건을 통과한 손상 점자블록 신고 지원

일반 위험물 안내와 손상 점자블록 신고는 서로 다른 기능입니다. 일반 위험물을 손상 점자블록 신고로 전송하지 않습니다.

## 권한과 신고 자료

카메라, 정확한 위치, 마이크, 신체 활동과 진동 기능은 각 안내에 필요한 범위에서 사용합니다. 목적지 검색·경로 요청과 허용된 신고 전송에는 네트워크가 필요합니다.

신고 자료 전송·보관 동의는 Android 권한과 분리되어 있고 기본적으로 꺼져 있습니다. 현재 내부 후보는 모자이크하지 않은 재인코딩 JPEG 원본, 정확한 GPS 좌표와 이동 방향, 신고 처리에 필요한 정보를 전송할 수 있으며 서버에 저장된 손상 점자블록 신고 원본(직접 신고·자동신고)의 정책상 보존기간은 180일입니다. 연구·학습 이용에는 별도 동의가 필요합니다.

## 게시 전에 해결해야 하는 사항

- 실제 대상 사용자의 실외 보행과 접근성 검증
- 지원 기기별 카메라·거리 측정·GPS·음성·진동 성능 확인
- TMAP 경로, 경로 이탈·도착 안내와 장애 상황 검증
- 손상 점자블록 자동·직접 신고, 동의 철회와 삭제 절차의 운영 검증
- 오탐·미탐과 잘못된 안내에 대한 안전성 평가
- 고정된 출시 후보를 대상으로 한 정식 시험과 출시 gate 완료

현재 계획된 정식 시험 279개와 출시 gate 5개는 모두 `NOT_RUN`이고 면제되지 않았습니다. 실제 휴대전화와 운영 환경의 검증이 끝나지 않았으므로 이 문안을 앱 스토어, 배포 페이지 또는 사용자 공지에 게시하면 안 됩니다.

쉽게 읽는 내부 사용자 설명 초안은 [USER_GUIDE.md](USER_GUIDE.md)를 참고합니다.
