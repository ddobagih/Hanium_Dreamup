# User Feedback

이 패키지는 위험/길안내 결과를 Android TTS와 haptic으로 전달하고 반복 알림을 억제한다.

- `WalkSafeFeedbackPolicy`: metric source, confidence, 3프레임 이상이면서 700ms 이상인 track 안정성, stale 상태와 cooldown을 검사한다.
- `AndroidFeedbackActuator`: TTS, 위험 진동, 길안내 진행음을 실제 기기 API로 출력한다.
- TTS 초기화 중 발화 요청은 `UNAVAILABLE`이며 음성 소유권을 확보하거나 과거 위험·길안내 문장을 보관·재생하지 않는다. 초기화 실패·한국어 미지원·close도 구분한다. `READY` 후 Main은 최신 관측의 위험을 재평가하고 현재 길안내를 재생성한 뒤, 원래 기한과 요청 소유권이 유효한 상호작용을 이어 처리한다. 초기화 확인 poll이 콜백보다 먼저 준비 상태를 보아도 같은 순서를 거치며 중복 제출하지 않는다. 위험은 원 관측의 기한과 현재 생산자·출력 조건을 실제 발화 시작에도 확인하고, 이미 시작한 발화의 완료는 해당 소유권으로 처리한다.

Main은 전달 결과와 현재 외부 음성 출력의 소유 상태를 확인해 앱 TTS·접근성 fallback·진동을 선택한다. TalkBack 활성 여부만으로 앱 TTS를 항상 차단한다고 해석하지 않는다. 500ms 상태 화면은 live region이 아니며 위험·상호작용·길안내의 중복/우선순위 창을 따로 적용한다. 진동은 실제 수준별 패턴과 전달 결과를 따르며 STOP 진동을 유지한다.

거리 없는 점형·횡단보도 참고 안내는 별도 관측·전달 정책과 `ADVISORY` 음성을 사용한다. 현재 관측·소유자·원 유효 기한을 확인하며, 횡단보도 참고는 현재 경로와 구간도 다시 확인한다. 참고 안내는 기존 위험·TMAP 음성을 선점하지 않고 거리·걸음 수·횡단 허가를 부여하지 않는다.

JVM policy 테스트는 실제 스피커 음량, TalkBack 순서, 착용 상태의 진동 체감을 검증하지 않는다.
