## 측정 조건과 해석 범위

각 유효 원출력 anchor에서 생산 파서와 같은 단일 최고 점수 클래스를 먼저 고른다.
그 클래스가 자기 임계값을 통과하지 못하면서, 다른 허용 클래스가 자기 임계값을
통과하는 경우를 센다. 클래스 순서·Float32 임계값·동점의 첫 클래스 선택,
유효 normalized XYWH 및 원사진 영역과의 교차를 적용한다. 차순위로 탐지를
대체하지 않고 NMS 전에 계산한다.

이 결과는 클래스 균형 정적 표본의 anchor 조건 진단이다. 객체 미탐수·recall·mAP,
전체 데이터의 발생 비율 또는 실제 보행/Android CPU·GPU·YUV 성능이 아니다.
OpenCV 입력과 앱 입력의 전체 1,487장 비트 동등성은 검증하지 않았다.
0건은 해당 표본에서 관측되지 않았다는 뜻이며, 합성 반례나 다른 영상에서의 발생을
부정하지 않는다. 특히 손상 점자블록 top1을 정상 점자블록 차순위로 바꾸면 안 된다.

기존 `YoloRawConflictingTactileStateTest`는 손상 .29/정상 .28 합성 반례의
거부, 임계값을 통과한 손상 클래스 보존, 별 anchor의 상충 상태 보존을 검사한다.
별도 uncertainty state는 원문에서 검토를 요구한 선택지다. 현재 단일 라벨·후단
차단을 유지하고, 이 측정만으로 새로운 증거 상태나 안내 권한을 추가하지 않는다.
