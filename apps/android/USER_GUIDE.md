# WalkSafe 사용자 설명서 초안

> 연계 산출물: `REL-17 사용자 설명서`  
> 문서 상태: `DRAFT` · `NOT_APPROVED`  
> 출시 상태: `NOT_ELIGIBLE`

이 문서는 현재 Android 사용자 앱 후보를 비전공자도 이해할 수 있게 설명한 내부 검토용 초안입니다. 정식 사용자 설명서나 공개 출시 안내가 아닙니다.

## 가장 먼저 알아야 할 내용

워크세이프는 시각장애인의 도심 보행 중 가까운 위험과 이동 방향을 알려 주고 손상 점자블록 신고를 돕는 안드로이드 보행 보조 서비스입니다.

워크세이프는 보행 안전을 보장하지 않으며 흰지팡이·안내견·보호자를 대신하지 않습니다.

현재 앱은 내부 구현과 자동검사를 진행한 상태입니다. 실제 휴대전화, 실외 보행, 소음 환경, 접근성, 위험 탐지 정확도와 신고 전송을 포함한 정식 시험은 끝나지 않았습니다. 따라서 일상 보행에서 이 앱만 믿고 이동하면 안 됩니다.

## 처음 보행하기 전에

WalkSafe는 전맹 사용자와 저시력 사용자를 같은 우선순위로 지원합니다. 화면읽기, 큰 글자와 고대비 설정을 확인할 수 있지만 어느 한 설정만 사용한다고 다른 사용자보다 우선하거나 접근성 검증이 완료된 것으로 보지 않습니다.

1. 교육 대상 로그인 ID를 입력하고 `교육 대상 로그인 ID 확인`을 누릅니다. 교육 기록은 이 ID별로 분리되며, 다른 ID로 바꾸거나 로그아웃하면 진행 중인 안내·연습은 취소됩니다.
2. 연령대를 선택합니다. 만 14세 미만은 계정과 보행을 시작할 수 없습니다. 만 14세 이상 18세 미만은 보호자 확인이 끝나야 계정을 활성화할 수 있습니다. 현재 후보 앱에는 실제 보호자 본인확인 서비스가 연결되지 않았으므로 보호자 확인이 필요한 계정은 보수적으로 차단됩니다.
3. `안전 제한 안내 듣기`를 누르고 음성이 끝날 때까지 기다립니다. 버튼을 눌렀거나 긴 문장을 읽었다는 사실만으로 교육이 끝나지 않습니다.
4. 실제 도로가 아닌 안전한 연습 장소에 멈춘 뒤 `안전한 연습 장소 확인`을 누릅니다.
5. 화면에 보이는 버튼으로 `위험 안내`, `일시정지`, `재개`, `안전정지`를 표시된 순서대로 연습합니다. 숨겨진 손짓이나 복잡한 메뉴는 필요하지 않습니다. 각 연습은 직접 버튼을 누른 뒤 한국어 TTS 재생이 끝나고 진동 요청이 수락된 상태로 비반복 패턴 시간이 지나야 완료로 기록됩니다.
6. 네 연습과 기기 기능 확인이 모두 끝난 뒤 Gateway에 로그인하고 새 보행을 시작합니다.

교육 완료 기록은 같은 기기의 계정별 앱 전용 설정에 남지만, 앱이나 휴대전화가 재시작돼도 이전 보행과 경로는 자동으로 이어지지 않습니다. 교육 기록을 바꾸기 전 안전 표식을 저장하지 못하거나 변경 결과를 끝까지 저장하지 못하면 현재 실행에서는 계정과 보행 기능을 열지 않습니다. 변경 도중 실패해 안전 표식이 남은 계정은 다음 실행에서도 과거 교육 완료 상태를 사용하지 않고 교육을 다시 요구합니다. 앱이 확인하는 진동 조건은 요청 수락과 패턴 시간 경과이며 실제 물리 진동 전달 여부는 실기기 시험 전까지 확인되지 않은 상태입니다. 오프라인 한국어 음성이나 진동을 사용할 수 없으면 연습과 보행 시작을 막고, 사용 중 필수 채널을 잃으면 보행 기능을 안전정지합니다.

## 휴대전화 장착 확인

- 휴대전화는 가슴형 또는 목걸이형 거치대에 고정하고, 렌즈가 정면을 향하며 옷이나 손에 가리지 않게 합니다.
- 손에 들거나 주머니에 넣은 상태는 공식 장착 방식이 아니며, 그 상태로 보행을 시작하거나 재개하지 않습니다.
- 앱이 방향·가림·흔들림·영상 품질 문제를 알리면 먼저 안전한 장소에 멈춰 장착을 교정합니다. 교정 뒤 앱이 상태를 다시 측정하더라도 사용자가 장착 상태를 명시적으로 다시 확인한 뒤에만 재개합니다.
- 제한된 재확인 뒤에도 문제가 계속되면 위험 안내를 신뢰하지 않고 모든 보행 기능을 안전정지합니다.

허용 높이·각도·흔들림 범위는 실제 사용자·기기 측정과 승인 전에는 임의로 정하지 않으며, 승인된 장착 근거가 없으면 정상 장착으로 판단하지 않습니다.

장착 확인을 통과해도 보행 안전이 보장되는 것은 아니며, WalkSafe는 흰지팡이·안내견 등 기존 보행 보조수단을 대신하지 않습니다.

## WalkSafe가 돕는 세 가지 일

### 1. 가까운 위험 안내

- 휴대전화 카메라로 앞쪽을 살펴보고 인공지능 모델이 가까운 위험 후보를 찾습니다.
- 조건을 충족한 위험은 짧은 음성과 필요한 경우 진동으로 알립니다.
- 위험 안내는 길안내와 다른 기능이므로 목적지를 정하지 않아도 작동하도록 설계되어 있습니다. 다만 목적지가 없는 상태를 포함한 전체 동작은 아직 정식 실기기 시험 전입니다.
- 휴대전화가 거리 측정 기능을 안정적으로 제공하지 못하면 미터 거리나 강한 위험 판단을 하지 않고 제한된 안내만 하거나 기능을 멈춥니다.

카메라와 인공지능은 위험을 놓치거나, 위험이 아닌 것을 위험으로 잘못 판단하거나, 위치와 거리를 잘못 계산할 수 있습니다. 안내가 없더라도 앞이 안전하다는 뜻은 아닙니다.

### 2. TMAP 큰 이동 방향 안내

- 사용자가 목적지를 검색한 뒤 후보를 직접 선택하면 TMAP 보행 경로를 요청합니다.
- 경로가 유효할 때 이동해야 할 큰 방향과 다음 안내를 음성으로 전달합니다.
- 위치가 부정확하거나 경로에서 벗어났다고 판단하면 이전 안내를 계속 사용하지 않고 현재 위치와 경로를 다시 확인합니다.
- 이 기능은 보행 가능한 모든 장애물이나 공사 상황을 확인한 ‘안전 경로’를 보장하지 않습니다.

길안내에는 위치 정보와 네트워크 연결이 필요합니다. GPS 음영지역, 지도 정보 지연, 통신 장애가 있으면 안내가 늦거나 중단될 수 있습니다.

### 3. 손상 점자블록 신고 지원

- 신고 대상은 `손상된 점자블록`입니다.
- 차량, 전봇대, 사람 같은 일반 위험물은 위험 안내 대상일 수 있지만 신고 대상으로 전송하지 않습니다.
- 앱이 손상을 여러 번 확인하고 위치·거리·중복 조건을 통과한 경우에만 자동신고 후보를 만들 수 있습니다.
- 사용자가 음성으로 직접 신고를 요청하는 흐름도 후보에 포함됩니다.
- 신고는 관리자 확인 대상입니다. 신고했다고 지도나 경로가 즉시 바뀌거나 보행 안전이 보장되는 것은 아닙니다.

자동신고 후보의 생성과 전송은 아직 실제 휴대전화·운영 서버에서 정식 검증되지 않았습니다.

## 권한은 왜 필요한가요?

Android 권한과 신고 자료 동의는 서로 다릅니다. Android 권한을 허용했다고 신고 자료 전송에 동의한 것은 아닙니다.

| 권한·기능 | 사용하는 이유 | 허용하지 않으면 |
|---|---|---|
| 카메라 | 앞쪽 위험과 손상 점자블록 후보를 찾음 | 카메라 위험 안내와 신고 후보 생성을 사용할 수 없음 |
| 정확한 위치 | TMAP 경로, 경로 이탈 확인, 신고 위치 확인 | 길안내와 위치가 필요한 신고를 사용할 수 없음 |
| 마이크 | 음성 명령과 직접 신고 요청을 인식 | 음성 조작을 사용할 수 없음 |
| 신체 활동·걸음 센서 | 이동량을 보조적으로 확인 | 걸음 기반 보조 계산을 사용할 수 없거나 제한됨 |
| 진동 | 중요한 위험 안내를 음성과 함께 보조 | 진동 안내를 받을 수 없음 |
| 네트워크 | 목적지 검색·TMAP 경로 요청·허용된 신고 전송 | 서버가 필요한 기능이 대기하거나 실패함 |

필요한 권한이 없거나 기기 기능을 믿을 수 없으면 해당 기능을 제한하거나 중단해야 합니다. 권한을 다시 허용했다고 이전 보행이나 경로를 자동으로 재개하는 것은 아닙니다.

## 손상 점자블록 신고 자료 동의

신고 자료 선택은 기본적으로 모두 꺼져 있으며 Android 권한·로그인과 별개입니다. 다음 네 항목은 서로 독립적입니다. 한 항목을 선택하거나 철회해도 나머지 항목이 자동으로 선택되거나 철회되지 않습니다. 다만 기능에 필요한 선행 선택이 없으면 그 기능은 실행되지 않습니다.

| 선택 ID | 사용자가 정하는 내용 |
|---|---|
| `RAW_SOURCE_COLLECTION` | 신고 확인에 필요한 원본 이미지·위치·탐지 자료를 기기에 수집할지 |
| `AUTOMATIC_REPORTING` | 조건을 통과한 손상 점자블록 후보를 자동신고 대상으로 처리할지 |
| `MOBILE_NETWORK_TRANSFER` | 정지 뒤 허용된 자료를 이동통신망으로 전송할지 |
| `TRAINING_REUSE` | 신고 처리와 별도로 승인된 자료를 모델 연구·학습에 다시 사용할지 |

동의하지 않거나 철회해도 기기 안에서 처리되는 위험 안내와 길안내는 계속 사용할 수 있습니다. `AUTOMATIC_REPORTING`을 꺼도 직접 신고와 다른 선택은 바뀌지 않습니다.

현재 동의 화면이 설명하는 신고 전송 자료는 다음과 같습니다.

- 메타데이터를 제거하기 위해 다시 인코딩한 색상 JPEG 원본 이미지
- 정확한 GPS 좌표와 GPS가 제공한 이동 방향
- 신고를 처리하고 중복 여부를 확인하는 데 필요한 탐지·시간·모델 정보

이미지는 모자이크하지 않으므로 주변 사람의 얼굴이나 차량 번호판 등이 포함될 수 있습니다. 180일은 현재 기술·운영 초안의 목표일 뿐 승인된 법적 보유기간이 아닙니다. 법적 보유기간, 보유 예외와 최종 한국어 동의·철회·삭제 문안은 외부 법률 검토와 승인 전까지 `NOT_APPROVED`입니다. 이 자료를 모델 학습에 사용하려면 `TRAINING_REUSE`를 별도로 선택해야 합니다.

현재 기술 계약에서 철회는 해당 선택의 새 수집·자동신고·전송·학습 재사용을 중단하고 아직 보내지 않은 관련 작업을 차단해야 합니다. 삭제는 철회와 다른 요청이며, 서버와 backup을 포함한 처리 범위·결과·증거를 별도로 확인해야 합니다. 재동의는 새 동의 version과 시각으로 기록해야 하며 과거 처리를 소급 승인하거나 진행 중인 삭제 요청을 취소하지 않습니다. 이 철회·삭제·재동의 흐름의 실제 운영 처리와 결과 확인은 아직 `NOT_RUN`입니다.

일반 활동원본은 보행 중 서버로 전송하지 않습니다. 정지 판정 뒤 `MOBILE_NETWORK_TRANSFER`를 선택한 경우에만 이동통신망 전송을 허용하고, 선택하지 않은 경우에는 Wi-Fi에서만 전송합니다. 이 설정을 바꿔도 Android 권한·로그인·나머지 세 선택은 바뀌지 않습니다.

TMAP 목적지 검색과 경로 요청에는 위치·목적지 자료를 외부 TMAP 서비스가 처리하는 제3자 경계가 있습니다. 제3자 제공인지 위탁인지, 국외이전이 있는지, 계약상 역할과 최종 고지·동의 문구가 무엇인지는 외부 계약·법률 검토 전에는 확정하지 않으며 현재 `NOT_APPROVED`입니다.

## 사용 중 꼭 지킬 안전 수칙

1. 흰지팡이, 안내견 또는 보호자의 도움을 평소와 같이 사용합니다.
2. 앱을 조작하거나 오류 내용을 확인할 때는 먼저 안전한 장소에 멈춥니다.
3. 앱 안내와 실제 주변 상황이 다르면 앱 안내를 따르지 말고 주변 상황을 우선합니다.
4. 카메라, 위치, 음성, TMAP 또는 거리 기능이 중단됐다는 안내가 나오면 해당 기능을 믿고 계속 걷지 않습니다.
5. 앱이 멈추거나 휴대전화가 재시작되면 이전 보행이 이어진다고 생각하지 말고 새로 상태를 확인합니다.

## 오류가 생겼을 때

- 위험 안내가 들리지 않으면 안전한 곳에 멈춘 뒤 음량, TTS, TalkBack과 카메라 상태를 확인합니다.
- 길안내가 멈추면 안전한 곳에 멈춘 뒤 위치 권한, GPS 상태와 네트워크 연결을 확인합니다.
- 신고가 실패해도 위험 안내나 길안내가 성공했다는 뜻은 아닙니다. 신고와 보행 보조 기능은 별도로 판단합니다.
- 앱이 기능을 제한하거나 안전정지했다면 원인이 사라지고 앱이 다시 확인하기 전까지 해당 기능을 사용하지 않습니다.

## 현재 검증 상태

- Android 코드의 내부 단위검사와 debug 빌드 검사는 수행 중입니다.
- W4의 formal 279, 실제 휴대전화 시험, TMAP live 연동과 배포는 모두 `NOT_RUN`입니다.
- W5에는 열린 finding이 남아 있으며 release signing과 deployment는 `NOT_ASSESSED`입니다.
- W7은 exact 3개 모델의 등록 완전성만 확인했습니다. 모델 평가는 `NOT_RUN`, 동등성 및 출시 승인은 `NOT_APPROVED`, release는 `NOT_ELIGIBLE`입니다.
- Web/PWA와 unsigned APK는 정식 Android release, 설치·배포 또는 사용자 검증 증거가 아닙니다.
- 따라서 이 초안과 현재 앱은 공개 출시 완료를 뜻하지 않으며 출시 상태는 `NOT_ELIGIBLE`입니다.
