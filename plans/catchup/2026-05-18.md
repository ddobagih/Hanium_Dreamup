## 확인 필요 / 보류
- 같은 sandbox 환경이면 Docker, local TCP, 포트 조회, ADB가 다시 막힐 수 있으므로 일반 개발 세션 또는 장비 접근 가능한 세션이 필요하다.
- Android에서 `127.0.0.1`은 휴대폰 자신을 가리키므로 ADB reverse, LAN IP, HTTPS 중 실제 경로를 먼저 고정해야 한다.
- `서울역으로 안내해줘`를 `set_destination`으로 확장할지는 제품 판단이 필요하다.
- `source=fake`는 UI/API/운영 흐름 근거이며 정확도나 실제 보행 안전 근거가 아니다.
- `source=server` headless PASS는 fixture smoke이며 실폰 목걸이 field 성능 근거와 분리해야 한다.
- v2 모델은 class `0 damaged_tactile_block` baseline이며 4-class 서비스 성능 근거로 쓰면 안 된다.
- `/` 가용 공간이 낮게 기록되어 대형 inference/full copy는 보류하거나 용량 gate 후 실행한다.
