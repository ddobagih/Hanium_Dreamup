## 현재 상태 요약
- 제품 방향은 시각장애인·저시력 보행자용 착용형 스마트폰 PWA다. 화면보다 TTS, 진동, 스크린리더, 음성 명령을 우선한다.
- v2 기준 흐름은 `fake-v2`/`server-v2`, `/detect/v2`, `/reports/v2`, tactile damage 자동 신고, voice-triggered v2 신고, admin v2 metadata 표시까지 구현되어 있다.
- `/detect/v2`는 아직 실제 YOLO26s/COCO 추론 adapter가 아니라 fake contract다. `server-v2`를 실제 모델 성능 근거로 쓰면 안 된다.
- PWA는 v2 상태 머신과 음성 신고 연결이 전진했지만 Android 실폰, 목걸이 착용, TalkBack, offline, 카메라/GPS/heading/TTS/진동 field 검증은 미완료다.
- Backend는 `/reports/v2`와 v2 정책 테스트가 구현되어 있으나 최신 PostGIS no-skip, HTTP smoke, upload/duplicate/cleanup 검증은 환경 gate가 필요하다.
- Model은 기존 tactile3 Stage1 `best.pt`가 현재 MVP 후보이고, reviewed tactile3 학습은 진행 중이다. `tactile_damage_area`는 FP/FN과 threshold calibration이 병목이다.
- Voice는 local/direct sample 근거가 있으나 실제 HTTP/CORS, 브라우저/실폰 mic, TTS HTTP cache/fallback/청취 검증은 미완료다.
- 2026-05-22에는 backend/model/PWA 회귀 50 tests, lint/typecheck/build PASS 근거가 있다. 2026-05-23에는 backend/frontend/voice 신규 테스트는 실행되지 않았다.
- 현재 브랜치는 upstream보다 8커밋 뒤처진 기록이 있고, 미추적 산출물이 많다. 새 PR/commit 전에는 범위를 파일 단위로 좁혀야 한다.
