## 리스크와 확인 필요

- 확인 필요: 실폰, USB 디버깅, ADB reverse, HTTPS 개발 URL 중 하나가 없으면 핵심 실폰 항목은 완료가 아니라 `수동 검증 대기`다.
- 확인 필요: Android에서 `localhost`와 `127.0.0.1`은 접속 방식에 따라 휴대폰 자신을 가리킬 수 있다. `3000`, `8000`, `9001` 포트 전략을 먼저 고정해야 한다.
- 확인 필요: `docs/execution/2026-05-15*.md`가 없어 5/15 실제 추가 실행 완료 근거는 제한적이다.
- 확인 필요: 현재 PWA server detector 변경은 미추적/미커밋 상태가 포함된다. 후속 에이전트는 diff 확인 후 이어서 작업해야 한다.
- 확인 필요: 최신 디스크 여유 공간을 다시 확인해야 한다. ONNX export, predictions 저장, failure sampling은 공간 부족으로 실패할 수 있다.
- 리스크: v2 모델은 class `0 damaged_tactile_block` 중심 baseline이다. 4개 위험 클래스 전체 성능으로 주장하면 안 된다.
- 리스크: fake 신고는 API/UI 통합 검증용이다. 정확도, 지연시간, 실제 안전 판단 근거로 사용 금지다.
- 리스크: `/reports`, `/uploads`, status patch는 인증 없이 열려 있다. 외부 공개 또는 장시간 네트워크 노출 전 제한이 필요하다.
- 리스크: Qwen3-TTS 동적 생성은 평균 2초 이상 기록이 있어 보행 중 위험 안내 primary path로 두면 안 된다.
- 리스크: Vibration API, DeviceOrientation, PWA 설치, Web Speech API는 브라우저/OS별 차이가 크다. Android Chrome 결과와 다른 환경 결과를 분리한다.
- 리스크: `/detect` 이미지 decode/추론 실패가 프론트 오류 표시와 혼동될 수 있다. ready/unavailable/error 상태 문구를 구분해야 한다.
- 리스크: `repeat_last`와 `speechEnabled=false` 조합에서 의도치 않은 음성 재생 가능성이 있으므로 회귀 확인이 필요하다.
- 리스크: 원본 음성, 생성 WAV, 데이터셋 이미지/라벨, `.pt`, `.onnx`, `runs/`, `outputs/` 산출물은 GitHub 업로드 대상이 아니다.
- 확인 필요: 실폰 테스트는 안전 확보된 실내/통제 환경에서 수행해야 하며, 실제 시각장애인 대상 현장 검증으로 표현하면 안 된다.
