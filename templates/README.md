# 한이음 제출 서식 공개 범위

이 폴더에는 Word·PowerPoint 원본을 저장하지 않는다. 제출 작업을 시작할 때
한이음의 현행 공식 배포처에서 새 양식을 받아 별도 비공개 작업공간에서 사용한다.

기존 개발보고서·제작설계서 원본, Word·PowerPoint 제출 후보와 그 생성
manifest는 현재 제품의 구현 대상이 아닌 legacy 자료다. 내부 이미지·문서
속성·원본 문서 식별 메타데이터가 있어 공개 `current` 브랜치에는 포함하지 않는다.

새 제출본이 필요하면 현행 코드와 근거자료로 별도 작업공간에서 만들고,
개인정보·이미지 출처·문서 속성 검수를 통과한 최종본만 새로 게시한다. 과거
submission builder와 validator가 제외된 legacy 파일을 요구하는 것은 의도된
안전 차단이다.
