# 별도 시각화 테스트 앱 소스

이 디렉터리는 휴대폰에서 사용한 별도 테스트 앱의 변경 소스를 보관합니다.
`overlay/`는 저장소 루트 기준 경로이며, 커밋된 원본 위에 복사해서 사용하는 파일 집합입니다.
원본 `apps/android`에는 이 파일들을 직접 덮어쓰지 않습니다.

## 분리하는 이유

- 원본 사용자 앱, 관리자 앱, 위치 평가 앱은 기존 `apps/android`에 유지합니다.
- 별도 앱은 지도와 객체 인식 확인 화면, 테스트용 초기화 및 센서 조정값을 포함합니다.
- `visualTest`는 `.visualtest` 패키지와 debug 서명을 사용합니다. 출시용 APK가 아닙니다.
- 여기의 `src/main` 변경에는 공통 코드도 있으므로 작업 폴더만 분리하는 것이 아니라 빌드할 때 반드시 `:app:assembleVisualTest`를 선택합니다. 이 복사본으로 출시 앱을 만들지 않습니다.

## 새 작업 폴더 만들기

저장소 루트에서, 부모 폴더는 존재하지만 대상 폴더는 아직 없는 절대경로를 지정합니다.

```bash
TEST_WORKSPACE="$HOME/walksafe-visual-test"
bash scripts/prepare_visual_test_workspace.sh "$TEST_WORKSPACE"
cd "$TEST_WORKSPACE"
python3 scripts/prepare_vosk_ko_small_model.py
```

스크립트는 **현재 브랜치의 커밋된 HEAD**만 내보냅니다. 미커밋 수정이나 다른 브랜치의 변경을 자동으로 가져오지 않습니다. 원본 수정 후에는 필요한 파일을 커밋하고 새로운 작업 폴더를 만듭니다. 기존 작업 폴더는 덮어쓰거나 삭제하지 않습니다.

로컬 SDK 경로, Vosk 다운로드, 키, 계정, DB, 기존 APK 및 실행 로그는 자동 이전하지 않습니다. Git에 추적된 객체 인식 모델 자산은 archive에 포함됩니다. API 키와 계정은 본문이나 소스에 적지 않고 로컬 설정으로 준비합니다.

자세한 빌드·설치는 [앱별 테스트 가이드](../../docs/guides/android-apps-testing-guide.md), 외부 HTTPS 연결은 [야외 테스트 가이드](../../docs/guides/outdoor-test-cloudflare-guide.md)를 따릅니다.

## 포함한 변경

- 지도와 객체 인식 화면, 화면별 source set 및 테스트.
- 객체 인식 초기화 진단과 거리 측정 상태 표시, 런타임 재시도 및 프레임 연속성 처리.
- 테스트용 GPS 정확도 일시 악화 유예와 휴대폰 흔들림 민감도 조정.
- 외부 HTTPS Gateway 주소 주입 및 저장된 이전 로컬 주소보다 테스트 빌드 주소 우선 적용.
- 일반 음성 소스와 목적지 안내 상태를 포함한 최신 별도 작업본의 관련 파일.

이것은 코드 보관과 재현 절차입니다. 원본 앱으로의 기능 통합 완료, 출시 적합성, 실제 보행 안전성 또는 위치 오차 2 m 달성을 뜻하지 않습니다. 센서 완화값을 원본에 옮기는 일은 별도 검토가 필요합니다.
