## EPIC-01 Phase C runtime metric preflight 구현·추적

- 사용자 Android 앱이 보행 기능을 시작하기 전에 별도 ARCore session에서 실제 미터 거리 프레임의 안정성을 검사하도록 구현했다. 사전검사 중에는 객체 탐지·길안내·신고·피드백·IMU를 시작하지 않고, 사용자가 시작을 확인한 뒤 새 runtime session에서 미터 근거를 다시 확인한다.
- 정책 계약 `1.0.0`은 최대 10,000ms, 서로 다른 프레임 10개 이상, 관찰시간 1,000ms 이상, 통과 프레임당 유효 표본 30개 이상, 통과율 0.80 이상, 0.2~8.0m 양끝 포함으로 고정했다. 생성기가 실제 Kotlin 상수와 비교하므로 코드와 문서가 어긋나면 실패한다.
