# 2026-09-04

## 위치 추적 정확도 개선

- Android 위치 추적 2m 목표 작업을 단계화하고 병렬 구현했다.
- Fused high accuracy 요청에 fine granularity와 cached fix 차단을 적용했다.
- 2D ENU 위치 추정기, predict 기반 Mahalanobis soft gating, 개인 보행속도 기반 process noise를 구현했다.
- 걸음 감지, 사용자별 보폭 보정, PDR, 저속 heading 선택 정책, 정지 감지와 ZUPT를 구현했다.
- 장착 방향과 편각 계약이 없는 자력계 heading 런타임 입력은 안전상 fail-closed로 유지했다.
- 활성 TMAP 경로 corridor 맵매칭과 raw/filtered/matched 좌표 분리를 구현했다.
- GNSS L1/L5 런타임 판정과 Raw GNSS C/N0 기반 multipath-risk shadow 신호를 측정 잡음 가중치에 연결했다.
- 위치 품질 LOW/UNAVAILABLE 및 회복 음성·진동 피드백을 경로 이탈 안내와 분리했다.
- GNSS, 센서, 보행 프로필의 권한·세션·계정·stale callback 수명주기를 연결했다.
- 독립 리뷰에서 발견한 PDR 이중 적분, ZUPT drift, 모호 경로 안내, 중복 표본, 센서 timestamp, GNSS 재등록, 회복 증거, 캘리브레이션 오염, 단절 전 도착 증거 문제를 수정했다.

## 위치 정확도 현장 검증 체계 및 가슴 고정 헤딩

- 연결 기기 `SM-S931N`(Android 16/API 36)의 GNSS L1/L5, raw measurements, IMU 및 자력계 capability를 확인했다.
- 디버그 전용 정확 위치 recorder를 추가했다. 좌표는 no-backup 영역에 목적 분리 키로 암호화하고, 명시적 확인 후에만 기록하며 SAF로만 평문 내보내기한다.
- 로그아웃·계정 삭제 시 purge fence, scope 회전, stale lease/SAF 차단을 적용했다. 삭제 실패 및 재시작 조합은 fail-closed로 처리한다.
- 확정 장착 규격 `PORTRAIT_BACK_OUT_TOP_UP_CHEST_CENTER`에서 device `-Z`를 전방축으로 사용해 자북 ENU heading과 편각을 진북 heading으로 변환했다.
- 자기장 크기·방향·경사·센서 freshness/accuracy·장착 자세 게이트와 1초/5샘플 복구 조건을 적용했다.
- accepted GNSS, 필터 좌표, current route match, PDR step, ZUPT, stationary, heading source/accuracy, GNSS quality/profile 및 측량 checkpoint를 공통 trace 계약으로 기록한다.
- 측량 checkpoint GeoJSON과 Android JSONL을 검증·세션 분할·튜닝·holdout 평가하는 표준 라이브러리 Python CLI를 추가했다. 실제 측량 증명과 별도 holdout 없이는 `TARGET_MET`을 내지 않는다.
