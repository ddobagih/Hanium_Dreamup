## WebXR Depth Sensor Hook 설계/구현 보조

### 한 일
- 지정 범위인 `apps/web/app/_walksafe/hooks/useDepthSensor.ts`에서 사용자 버튼 기반 WebXR depth-sensing hook 구조를 정리했다.
- `navigator.xr.requestSession("immersive-ar", { requiredFeatures: ["depth-sensing"], depthSensing: { usagePreference: ["cpu-optimized"], dataFormatPreference: ["luminance-alpha", "float32"], matchDepthView: true } })` 형태를 타입 안전한 local type으로 감쌌다.
- `frame.getDepthInformation(view)`는 animation frame 안에서 즉시 샘플링하고, 최신 중앙 depth sample은 `latestSampleRef`와 `state.latestSample`에 보관하도록 했다.
- 기존 `getUserMedia` 카메라 스트림은 hook 내부에서 건드리지 않도록 유지했다. WebXR AR 세션과 카메라 preview 충돌 가능성은 버튼 연결부에서 명시적으로 처리해야 한다.
- 병렬 작업자가 추가한 depth estimator 연동 흐름은 되돌리지 않고, depth frame 객체를 프레임 밖에서 직접 재사용하지 않도록 grid snapshot sampler로 완충했다.
