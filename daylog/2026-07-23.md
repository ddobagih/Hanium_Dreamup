## EPIC-01 Phase E 독립 Android Gateway 추출

- Android가 쓰는 `/api/field-session`, `/api/navigation/walking`, `/api/navigation/destinations/search`, `/api/reports/v2`를 `apps/android-gateway`의 독립 Node 22 서비스로 옮겼다. 기본 결속은 `127.0.0.1:8081`, 보호 Backend는 정확히 `http://127.0.0.1:8000`이며 다른 공개 경로는 404다.
- Android debug 기본 endpoint를 8081로 전환하고 Next/Backend fallback을 제거했다. 기존 Next 4개 route 파일은 삭제했으며 Legacy Web proxy는 모든 요청을 `410 Gone + no-store`로 종료하고 임시 허용목록을 0개로 만들었다.
- Gateway에 actor-bound 12시간 세션, 서버측 폐기, 내부 자격증명·actor assertion, body/upstream timeout, 로그인·신고 admission 제한, upstream 인증실패 502 변환을 구현했다. 신고 multipart는 metadata 1개 64 KiB와 JPEG 1개 1~8 MiB만 허용한다.
- 빌드는 package-local `dist`를 먼저 정리해 오래된 출력이 섞이지 않게 했고, client close 중 backpressure 대기를 종료·body cancel하도록 보강했다. 잘못된 request target은 400으로 분류한다.
- systemd·nginx·환경파일은 `DRAFT_DEPLOYMENT_EXAMPLE / NOT_APPLIED`로만 추가했다. nginx 예제는 query가 포함된 access log를 끄고 ingress 생성 응답에도 `Cache-Control: no-store`를 붙인다. 실제 설치·enable·start·reload는 수행하지 않았다.
- CI와 테스트 레이어에 Gateway install·typecheck·test를 추가하고 Phase D live 검사를 역사적 `EXPECTED_STALE`로 이동했다. Phase D builder·test·8개 출력 10개는 기존 SHA-256 그대로 보존했다.

## 독립 검토 반영

- 정책 검토에서 발견한 gate 선행순서를 바로잡았다. 단일 관리자 복구훈련은 실제 사용자시험 전, 휴대전화 queue byte 한도는 지원기기 시험범위 확정 전, 서버 용량계약은 관련 통합시험 완료 전, 원본수집 검토·고지·동의·권리행사는 TST-22·배포 전에 닫는다. 원본 검토 변경 요구는 CR·영향분석·제품책임자 재승인으로 연결하고 비용 gate는 저장·요청·복원 비용을 포함한다.
